# 落子無悔 V1.3.1 方案：角色做完整（已實作，進度見 §8）

> 2026-11-08。基於 V1.3.0。三方（Claude、Codex、Antigravity）討論三輪：第 1 輪各自獨立提案，第 2 輪互評，第 3 輪定稿。過程在 `coordination/v131-r1～r3/`，底稿 `coordination/v131-r1/seed.md`，裁決 `coordination/v131-ledger.md`。
> 使用者的要求：基於 V1.3.0 完整做完、要加什麼都能加，一定要做角色。

## 0. 原則
- 純畫面：模擬、數值、舊對戰碼、重播、殘局解都不變（`FINGERPRINT b8fe741bcbfcf800`、數值摘要 `288176c5c9af5a79`）。命中時間點 `ATK_WINDUP` 與命中映射不動。
- 效能與資源（Codex 第 3 輪門檻，相對 V1.3.0）：
  - 同機交錯量測五組，各情境 p95 中位數不增加。
  - 常駐圖集增量 ≤ 104 MiB。
  - 程序常駐記憶體增量 ≤ 160 MiB。
  - 烘焙峰值增量 ≤ 320 MiB。
  - 十次冷啟動中位數增量 ≤ 0.5 秒（量到可操作且必要圖集就緒）。
  - 任一項超標：先優化，再考慮退回。
- 簡化特效、簡化介面、色盲、手把、兩語三字級版面都要過；零預算（程式繪製）。
- 造型描述一律以程式為準（第 2 輪 Codex 核對出 8 處錯誤描述，見 §2）。

## 1. 現況（V1.3.0 留下的角色問題）
- **轉身**：真轉身影格只有 6 種（劍士、盾兵、騎兵、長槍兵、史萊姆、小石魔）。其他 16 種只是最窄 0.45 的厚木牌翻面。
- **轉身做法的限制**：
  - `_part(z, fwd)` 只換座標，不換畫序，所以遠近配件過中線時不會對調前後。
  - 轉身影格用的是待機腿：走路中轉身時，腿會停住約 0.15 秒。
  - 出手中轉身時，整張圖被夾成 0.45 寬。
  - 更窄的兩格轉身影格不畫表情。
- **穿幫**（第 2、3 輪確認）：
  - 小石魔：轉身時肩甲往內夾，把臉擠窄（`fantasy.gd:307`）。
  - 史萊姆：高光烘在左側，翻面時跳到右邊（`fantasy.gd:133`、`sprite_cache.gd:279`）。
  - 劍士：勝利姿勢的刀刃穿過眼睛（`kingdom.gd:79`）。
  - 投彈兵：手上的火罐要到 `w>0.25` 才消失，但飛行從前搖開始就出發了；飛行起點是身體上的固定偏移，不是手的位置（`kingdom.gd:185`、`battle_units.gd:480/484`）。
- **剪影**：投彈兵、骷髏法師和盾兵的輪廓接近；大、小史萊姆同形；刺客是平頭方塊；狂戰士的雙斧貼著身體。
- **還缺的生命感**：
  - 沒有兵種專屬的待機小動作。
  - 弓箭手、投彈兵、醫者、骷髏法師的攻擊姿勢和待機差不多。
  - 勝利姿勢和待機太像。
  - 受擊時配件不會動。
  - 圖鑑大圖固定側面。

## 2. 三方查核（說了但改掉的）
- **Antigravity 第 1 輪的造型描述與程式不符，以程式為準**：
  - 骷髏法師拿的是書＋紫火，不是骨杖水晶。
  - 吸塵貓是直立圓身，背著桶、前伸吸嘴，不是長身。
  - 弓箭手頭上的是帽羽，不是箭羽。
  - 投彈兵的橙色是頭巾，不是頭髮。
  - 孢子菇有 4 個白斑，底部是芽，不是腳。
  - 爆爆羊的引線在頭上，不在背上。
  - 巫毒娃娃的眼睛是鈕扣＋X，沒有鏡片。
  - 骷髏 21 拿骨刀，不是空手。
- **投彈兵攻擊時手是空的**：這是設計，火罐在前搖時就飛出去了。真正的錯是放手時機和飛行起點不同步，只加殘影修不好。
- **小石魔肩甲夾臉**：部分屬實，是把臉擠窄，不是整張臉被蓋住。
- **走路中轉身**：Antigravity 的墊步跳不採用。落地時腳點仍會跳變，木座微傾也會讓人看不出落地位置（Codex 提出，Antigravity 第 3 輪接受）。
- **落後時的冷汗＋顫抖**：混戰中容易被看成暈眩或冰凍，改成靜態表情，列 P2。
- **待機小動作用執行期部件動畫**：要拆件、補遮洞、改畫序，還會增加繪製提交次數，改成烘焙影格。

**1. 其餘 16 種真轉身**
- **兩趟畫序**：每種兵分兩趟畫：先畫遠側配件，再畫身體與頭，最後畫近側配件。依轉角決定每個配件屬於哪一趟；每個配件重設矩陣，直接用 `draw_*` 畫的部件也要納入群組。
- **中線防閃爍**（Antigravity 第 3 輪）：在中線（最窄格）時，配件要停在正側面的極值，和身體的重疊最少，或一前一後錯開。禁止在臉的正前方、同一格內對調前後。
- **錨點**：每種兵定義臉錨點，以及武器的線段或多邊形錨點。
- **一併修**：小石魔肩甲改成往外開或往下移；史萊姆高光固定在世界的左上方。
- **記憶體**：轉身頁擴到 22 種，共 132 格、3072×1728、20.25 MiB（比現在多 13.5 MiB），不用分頁。
- **逐種難點**（依程式造型）：

| 兵種 | 難點 |
|---|---|
| 弓箭手 | 箭筒在遠側、弓手在近側；弓轉正時弓面要變寬 |

| 投彈兵 | 背包在遠側、火罐手在近側，火罐不縮 |
| 醫者 | 帽和頭分開，法杖手獨立 |
| 鼓手 | 帽羽、鼓、雙槌分組；鼓面轉正時壓成直立橢圓 |
| 狂戰士 | 肩帶跟身體，雙斧分遠近 |
| 孢子菇 | 芽、柄、圓傘分組，圓傘不縮 |
| 爆爆羊 | 長身體會縮，圓頭不縮，四條腿分組 |
| 寶箱怪 | 箱、蓋、舌分組，要補畫箱子側面 |
| 幽靈 | 雙手分遠近，尾裙延遲擺動 |

| 骷髏法師 | 兜帽、書手、火分組 |
| 吸塵貓 | 尾巴和桶在遠側、吸嘴在近側，頭和耳朵不縮 |

| 骷髏 | 頭不縮，骨刀在近側，雙腿分組 |

**3. 表情與特效跟錨點**
- 拿掉「窄格不畫表情」的限制。
- 臉、盾光、槍光各自跟自己的錨點。
- **窄格最小像素保護**（Antigravity 第 3 輪）：臉寬小於 3px 時，只畫單眼和情緒符號，或畫半張臉，不把整組五官硬塞進去。

**4. 剪影 5 改**
- 投彈兵：肩上的桶微微凸出。
- 骷髏法師：書和紫火往前探，兜帽尖往後翹。
- 大史萊姆：頭頂加冠。
- 刺客：圍巾改成往上翹的短燕尾。
- 狂戰士：待機時雙斧往外開，但比攻擊時舉斧低。
- 驗收用原尺寸的黑剪影盲辨。

**5. 既有穿幫**
- 劍士：勝利姿勢的刀刃整片避開臉。
- 投彈兵：統一「放手事件、手部錨點、飛行起點」三者，命中時刻不變。

**6. 驗收工具**
- 全 22 種兵、紅藍兩隊、左右兩個方向的轉身逐格條。
- 錨點檢查用武器的完整線段或多邊形，不只看尖端：不能進入臉框，也不能超出格子。

### P2（37～65 人時）
- 落後時的表情：低頭咬牙，木座微沉 1px；不抖、不畫汗滴。
- 奇幻兵死亡時的遺物落地。
- 全角色的高光不跟著翻面。
- 角色專屬的小音效。
- 最後一擊的定格。
- 鼓舞與歡呼的波浪傳導。
- `_hand_ring` 幾何快取。
- 格子模式的擺陣沉降。
- 抓起時亂踢的姿勢。

### 不做
- 台詞泡泡、外觀收藏：兩方都反對，會遮住角色，也會分散這一版的焦點。
- 走勢圖改非線性：會誤導。
- 攻擊中間的轉身影格：約 297 MiB，太大。

## 5. 不改就不能上（三方第 3 輪條件）
1. 四相位要分頁，退回門檻要定死（§0）。
2. 投彈兵的放手事件、手部錨點、飛行起點要統一，命中時刻不變。
3. 小石魔肩甲、劍士刀刃、史萊姆高光，以及全角度錨點，都要通過驗收。
4. 四相位與八相位接合，或退回方案，都不能跳腳。
5. 窄格最小像素保護；中線格的配件錯開，不閃爍。
6. 指紋、數值摘要、p95、無障礙都不能退步。

## 7. 參考資料

  - [GarageFarm](https://garagefarm.net/blog/idle-animation-tips-to-animate-your-characters)
  - [WigglyPaint](https://wigglypaint.com/blog/pixel-art-animation-guide/)

- 跟隨動作、重疊動作可以用程式算（[Game Developer：12 原則](https://www.gamedeveloper.com/production/the-12-principles-of-animation-in-video-games)）。
- Antigravity 參考的作品：Wildfrost、Cult of the Lamb（待機的玩具感）；Super Auto Pets、Slay the Spire（情緒）；Into the Breach、Hades（出手與打擊）；Ori（物理慣性）。
