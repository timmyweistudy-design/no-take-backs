# 排版規則例外清單（V1.5.2）

每條例外都在程式裡用 `probe_skip(規則, 理由)` 宣告，版面報告會列出。新增例外要同時寫進這裡。

| 畫面 | 規則 | 理由 | 位置 |
|---|---|---|---|
| 規則大廳（`22_lobby` 等） | R4 | 底列刻意分兩組：左側操作（返回、展開、隨機／代碼）靠左，右側「開始」主按鈕靠右 | `lobby_view.gd` `_draw_lobby` |
| 圖鑑近看（`10c_codex_zoom`） | R6 | 中間是角色大圖，角色圖不經版面探針，不是空白 | `codex_view.gd` `_draw_codex` |
| 殘局提示框 | R4 | 底列跟內文同一條左線：揭曉／套用在左，返回靠右對齊內文右緣 | `game_modes.gd` `_draw_puzzle_hint` |
| 殘局出題台（`v16_13_editor`） | R6 | 中間是 16×9 小棋盤，格子直接畫、不經版面探針，不是空白 | `game_v16.gd` `_draw_editor` |
| 結果頁老闆便條（`v160_05g_note_pin`，1.6.0 B06） | R1 | 桌位表固定位置：結果紙外左下桌緣（方案 §1、P1.5），刻意不置中 | `ui_base.gd` `_note_pin` |
| 殘局／教學選關 | R4 | 三段式底列：左＝總星數文字、中＝返回（本身置中）、右＝「只看未滿星」開關 | `game_menus.gd` "tutorial"／"puzzles" |

不算例外、而是規則本身的判斷：
- 格狀排列（禁用牌 20 格）最後一排靠左：R4 會認出是格線的最後一排，不當成按鈕群組。
- 設定頁底部「製作名單／返回」以中央操作欄中線（620）置中：用 `probe_axis` 宣告，不是例外。
| 元件庫展示（`v120_00_components`，開發用） | R6 | 下半是材質樣本與黃銅開關，直接畫、不經版面探針，不是空白 | `tools/dev_main.gd` `_draw_kit_demo` |
| 表情對照（`v120_03_moods`，開發用） | R6 | 角色直接畫、不經版面探針，不是空白 | `tools/dev_main.gd` `_draw_mood_demo` |

### 1.5.0 R14（一頁一件事）的登記豁免
可見可點元件超過該類上限時，畫面必須用 `screen_register(類別, 主動作, 理由)` 寫明理由，否則已改造的類別（標題、結果、大廳、擺陣、設定）算失敗。

| 畫面 | 規則 | 理由 | 位置 |
|---|---|---|---|
| 大廳（進階折頁打開） | R14 | 折頁內部重排（卡池單側＋唯讀摘要、分頁收斂）排在後面的批次 | `lobby_view.gd` `lb_why` |
| 大廳（「我的預設」選單展開） | R14 | 選單本身是一張清單（每列讀取／存入／刪除） | `lobby_view.gd` `lb_why` |
| 結果「詳細數據」分頁 | R14 | 「造成／承受」切換是這一頁的內容控制 | `game_result.gd` `r14_why` |
| 結果（系列結束） | R14 | 三枚木印章可點開看詳情 | `game_result.gd` `r14_why` |
| 結果「走勢」分頁 | R14 | 時間軸關鍵時刻與「還有 N 條」是內容展開 | `game_result.gd` `r14_why` |
| 自由部署（「工具」抽屜展開） | R14 | 貼齊、密集兩個開關暫時多出來；收合時在上限內 | `game_place.gd` `_draw_place_hud` |
| 設定（剛套用一鍵預設） | R14 | 多一顆「撤回」，暫時 | `game_menus.gd` `_draw_settings` |
| 設定「資料」抽屜（有舊實驗簿時） | R14 | 多一列「匯出舊實驗簿」：只有 V1.6.1 以前的存檔才有 | `game_menus.gd` `_draw_settings` |
| 覆盤「棋課本」頁（`v160_16c_lesson_book`） | R6 | 覆盤面板三頁（改動、讀結果、棋課本）共用固定高度；棋課本筆數少時下面留白，每頁筆數照字級算 | `replay_view.gd` `_rv_draw_book` |
