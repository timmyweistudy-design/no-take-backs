# 試玩包說明（給試玩者，1.0.0）

1. 解壓縮，執行 `NoTakeBacks.exe`。Windows 可能跳 SmartScreen，按「其他資訊→仍要執行」。
2. **先不要看任何說明，也不要問主持人**，照遊戲自己的引導玩大約一小時：開遊戲 → 教學 → 第一場對 AI → 右上角「建議下一步」→ 之後想玩什麼就玩什麼。
3. （選做）進「設定 → 操作」把「試玩紀錄」打開：每場戰鬥會記結果，戰鬥中覺得已經知道誰會贏就按右上角「我知道誰會贏了」，每場結束給一個激烈度分數。
4. 玩完按 暫停選單（Esc）或「設定 → 資料」的 **「回報問題」**：內容會複製到剪貼簿，也會存成存檔資料夾裡的 `report_<時間>.json`。畫面提示會告訴你有沒有存到。把剪貼簿內容貼回來，或把那個 json 檔寄回來；有開試玩紀錄的話也一起寄 `playtest_log.jsonl`（「設定 → 操作 → 打開紀錄資料夾」）。
5. 隔天如果還願意，再開一次遊戲玩 10 分鐘（看「繼續」捷徑記不記得你玩到哪）。

遊戲不會自動上傳任何東西；回報只有本機的遊玩進度摘要和你的評分。主持人看什麼見 `docs/playtest/protocol.md`「V1.0.0 發版門檻」。
