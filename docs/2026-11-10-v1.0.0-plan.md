# 落子無悔 V1.0.0 正式版整合方案（定稿，三方五輪後）

> 狀態：**只規劃、不實作**。討論紀錄 `coordination/v100d/`（r0～r5、`ledger.md`）。
> 三方：Claude（主持、產品、內容）、Codex gpt-6.1-sol（工程：程式、效能、存檔、測試、Steam）、Antigravity Gemini 3.8 Flash（體驗與美術；Argon 額度用完）。
> 符號：優先 **P0**＝發行前一定要、**P1**＝1.0.0 要做、**P2**＝有餘力／1.0.x；成本 小／中／大；「離線可驗」＝不用 AppID、不用 Deck 實機也能驗收。

## 0. 定位與原則
1. **V1.0.0＝第一個公開正式版。** 內部 1.0.x～1.6.1 從沒公開（沒有 AppID），全部當開發史併入。App 版本改 1.0.0（`project.godot:14`、`export_presets.cfg:29,30,90,91`，含 `product_version`）；產品名不改（避免 `user://` 路徑變）。
2. **改號不動資料契約。** 存檔 `SAVE_VERSION` 3 不升（只有破壞性欄位才升）；代碼前綴（NTB*／NTBR*／NTP1～4／NTC1／NTW1／NTS1）、`RULES_VERSION`、`Daily.VER`、`Rift.VER` 全不動；FINGERPRINT b8fe741bcbfcf800 與舊 digest 守住。
3. **方向：收斂、補洞、驗證，不是加量。** 內容已經很多（120 殘局、30 試煉、20 三考、22 兵；玩法入口約 20 個，見 §4 對照表）；1.0.0 的問題是入口多、說法散、失敗路徑有洞、沒有真人與實機驗證。
4. **角色只改表現不改模擬**：不改時序、不延後可攻擊、不暗示不存在的能力；新特效限在剪影內或 0.3 格內，「減少特效」時不出。
5. **所有主張要可查**：程式行號、截圖、外部網址；不實的寫進裁決不採用（Gemini 第 3 輪把 12 種不存在的兵寫進逐兵表，整段不採）。
