# 落子無悔 V1.5.0 完整方案（定案，未實作）

> 2026-11-09。使用者要求：基於 V1.4.0 列出 V1.5.0 完整方案，三個重點：客製化全面深挖、主畫面減到約五顆大鈕、角色建模修好（遠程沒射東西就傷人、圖鑑手持物像被裁掉、轉身像紙片）；查資料、先不做、三方討論三輪。
> 過程：`coordination/v150-r1`（簡報與各自提案）→ `v150-r2`（交叉裁決）→ `v150-r3`（定案）。角色檢查證據圖在 `docs/review/v150/`。
> 原則不變：舊對戰碼、重播、模擬指紋（`FINGERPRINT b8fe741bcbfcf800`）不能變；V1.5 **不新增戰鬥機制與規則欄位**，所有角色與演出只動畫面。

## 0. 為什麼要做（查證過的現況）
- **主畫面有 13 顆按鈕**：主玩法 4、次 4、每日、遊戲間、系統 3；遊戲間、戰績頁裡還藏了 8 個玩法與功能。
- **設定只有 18 項**（4 頁），主要是基本畫面、音量與輔助；觀戰顯示、輸入細節、資料管理都沒有。
- **角色**（自製檢查表 `docs/review/v150/audit_0～3.png`：22 種兵 × 正側面、三個轉身角、前搖、揮擊、朝左、受擊，圖鑑同 2 倍）：
  - 轉身：大部分部件只做水平縮放，臉一直朝正面，看起來像紙片翻面。待機轉身已有部分部件位移；攻擊途中轉身則完全退回水平壓扁。
  - 遠程：
    - 弓箭手的箭要飛 0.28 秒，但目標的受擊閃白和數字在事件到的當下就播（`battle_view.gd` `hurt_t[t.id] = time`），所以箭還沒到人就受傷。
    - 弓箭手前搖時弓上沒搭箭。
    - 投彈兵前搖有拋物線，但手上的火罐沒交接、飛行很短。
    - 骷髏法師書上的紫火沒飛出去，只在自己身上一個揮擊特效。
    - 孢子菇只在目標身上冒孢子。
  - 手持物：
    - 劍、刺客短刀沒畫握柄與柄頭，刀身直接插在手上，看起來在手的位置被切斷。
    - 長槍桿穿過手，沒有手指包住。
    - 圖鑑裡騎兵的槍尖伸進名稱區（`codex_crop.png`）。
- **查到的參考**：
  - [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/)：分基本、中階、進階；可調速度、設定要存、遊戲內說明無障礙功能。
  - [Xbox Accessibility Guidelines 101／104／107](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/101)：文字大小可選、完整重綁、按住改切換；第一次啟動在主選單前先問無障礙設定。
  - [The Last of Us Part II](https://blog.playstation.com/2020/06/09/the-last-of-us-part-ii-accessibility-features-detailed)：三組預設一鍵套用再細調。
  - 設定選單資訊架構：分類、常用在前、進階收合、手把可操作（[bugnet.io](https://bugnet.io/blog/how-to-design-a-settings-menu-thats-comprehensive-but-not-overwhelming)）。
  - 2D 轉身：多角度、五官錯動、遮擋、少量伸縮（[Spine 論壇](https://fr.esotericsoftware.com/forum/d/11466-25d-face-rig-ideas)）。
  - Riot 清晰度：特效要分層級，普攻不能蓋過重要訊息（[Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)）。

## 2. 客製化與設定
### 2.1 設定頁結構
- **七個分頁**：畫面、介面、聲音、操作、戰場與觀戰、無障礙、資料。
- **不做文字搜尋**（手把打字慢）。每頁上面 3～5 項常用直接顯示，次要的標「〔進階〕」收合。
- **其他頁面功能**：
  - 右欄即時預覽與一句說明。
  - 單項、每頁「恢復預設」。
  - 視窗變更提供限時復原。
  - 標出「已修改」的項目。
- **無障礙一鍵預設**（設定首頁頂端三張卡，可疊加，套用前列出差異、可撤回）：
  - 視覺清晰：150% 字級、一般標題、高對比底板、加強焦點。
  - 低動態：減少動態、震動 0、閃白關、靜態主畫面、固定鏡頭、自動慢動作關。
  - 低操作負擔：點選擺放、切換操作、擺放確認開、提示手動關閉。
- **第一次啟動**：主選單前先問語言、字級、無障礙預設三件事，可跳過；升級的玩家不重問。
- **戰鬥中暫停**也能開設定，每項標「立即生效／下一局生效／目前不可用」。
- **影響對局的東西不放全域設定**：
  - 難度輔助：自由對 AI 大廳的「調整難度」捷徑，寫入既有讓子預算與 AI 等級，結果、戰報、重播標「自訂」；固定挑戰與遠征不適用。
  - 規則：照舊在大廳，我的預設由 5 格擴為 10 格（可命名、覆寫確認、複製代碼、可捲動清單）。
- **塗裝**：設定裡只放「開啟塗裝室」入口，同一份資料。

### 2.3 固定行為（不給開關，避免設定膨脹）
- 隊伍形狀標記常駐；必要投射物與危險範圍永遠看得到；重要狀態與事件文字保留。
- 數字等寬、同類音效限流防爆音、倍速保持音高、失焦音訊降低。
- 全畫面刺眼閃光停用；雙人交接遮罩、退出與覆寫二次確認。
- 按鍵圖示自動偵測；捏合、滾輪、縮放按鈕並存。
### 2.4 延後（不放空殼開關）
- 175% 字級、任意介面縮放、亮度調色、角色描邊粗細。
- 血條刻度、飄字大小與密度細調、鏡頭特寫。
- 連續塗兵、右鍵語意自訂。
- 新底漆、桌布、旗幟、刻字、署名。
- 文字朗讀、多人存檔、固定種子、新規則欄位。

## 3. 角色（重點，先做好再管容量）
### 3.1 遠程演出與時間同步（只動畫面）
- **展示時間軸**：
  - 沒有手動軍令的對局（大多數）：展示緩衝從 2 tick 加到 8 tick（0.4 秒）。
  - 有手動軍令的對局：維持 2 tick，配快速飛行。
  - 每種兵分配「前搖＋飛行」預算，不夠就縮短演出，不能憑空飛彈。
- **一律照展示時間播**：
  - 位置、狀態、召喚、分裂、連鎖、HP、死亡、閃白、數字、音效、事件列。
  - 最後一個有效事件播完才進結果頁。
  - 暫停凍結；倍速沿同一游標前進；跳轉才重建快照、投射物與去重狀態，不補播沿途音效。
- **逐兵種**：
  | 兵種 | 演出 |
  |---|---|
  | 弓箭手 | 前搖從箭袋抽箭搭弦、箭尾跟弦；淺拋物線；箭尖到才扣血；插著抖 |
  | 投彈兵 | 火罐在手上（引信火花），離手當幀交接給飛行物；高拋物線、旋轉；落點一次爆炸涵蓋主目標與波及 |
  | 骷髏法師 | 書頁紫火聚成火種，低弧飛出、拖尾；紫色碎光命中 |
  | 孢子菇 | 傘緣噴孢子飄向毒圈範圍（是毒圈，不畫成單體彈）；毒傷 tick 時目標冒小毒標 |
  | 巫毒娃娃 | 保留綁定線，傷害時脈衝沿線傳遞 |
  | 醫者 | 杖頂十字聚光，沿治療弧線飛到友軍 |
  | 吸塵貓、沙漏精靈、鼓手 | 依原本範圍機制（氣流、沙粒波紋、聲波圈），不畫成單體彈 |
- **回歸案例**：移動目標、施放者先死、同 tick 死亡、多彈同點、範圍命中、召喚、分裂、連鎖傷害、結算前最後一擊。
### 3.2 手持物
- **錨點**依持物類型配置：握點、柄尾、護手、刃根、尖端、發射點。魔導書、火罐不硬填無意義欄位。
- **手**分「掌後片」和「手指前片」，畫序是三明治：遠手／掌後 → 握柄 → 手指 → 護手／刃身。實際順序依角度調整。
- **長柄物分段**：長槍、騎槍等穿越身體前後的物件分成前後兩段。
- **離手交接**：離手當幀從手持物交接給投射物，不會出現空窗或兩份。
- **逐種清單**：
  - 劍士補柄頭、握柄、護手。
  - 刺客雙手反握短刀，各自有握點。
  - 長槍兵、騎兵的手指覆在桿前。
  - 弓箭手弓把、拉弦手、箭、弦各自有錨點。
  - 醫者手包住杖身。
  - 鼓手鼓槌有短柄尾，敲擊終點落在鼓面。
  - 狂戰士雙斧分斧頭、柄、手，側身時遠斧被身體遮住。
  - 骷髏法師托住書脊。
  - 吸塵貓吸管接到背後集塵桶。
- **無持物的兵**只驗收輪廓與動作，不硬套握持骨架。
### 3.3 轉身不像紙片
- **角度系統**：一套共用的部件角度系統，0° 右、90° 正面、180° 左、270° 背面。每個部件有深度，依「旋轉後深度」排畫序，所以近遠手會交換；深度相同時用穩定次序，避免閃爍。
- **關鍵姿勢**：每個輪廓族群定 8 個方向的關鍵姿勢（輪廓、遮擋、握持），中間用幾何插值。可見性與遮擋依姿勢規則切換，不是圖片淡入淡出，背面不能用鏡像代替。
  - 人形：共用頭、肩、手腳骨架。
  - 騎兵：人、馬、槍分開轉。
  - 蘑菇與史萊姆：保體積，五官繞體移動。
  - 寶箱怪：蓋板、箱體、鉸鏈有厚度。
  - 幽靈：臉跟著轉，尾部與雙手錯動。
  - 娃娃：球頭、鈕扣眼、縫線與針方向一致。
  - 沙漏：框架、玻璃、翅片分層，側面仍有框厚。
  - 吸塵貓：耳、背包、吸管分開。
  - 石魔：肩甲、拳、軀幹有側面面積與遮擋。
- **臉**：
  - 五官隨角度沿頭部移動；遠側眼變窄、被輪廓遮住，側面補鼻尖或嘴的小輪廓，背面不畫眼。
  - 表情疊加層跟著角度偏移。
  - 轉身時軀幹先轉、頭先看向目標、武器稍後跟上。
- **圖集**：
  - 圖鑑與直接繪製用連續角度。
  - 戰場圖集：待機轉身頁擴到含正面在內的多個角度（5～7 個是 M1 試作範圍，依輪廓品質、記憶體、烘焙時間定案）；走路轉身維持 1～2 個中繼角。
  - 攻擊途中轉身改走新系統（圖集沒有的就當幀直接繪製），不再水平壓扁。
- **既有基礎**：`kit.gd` 已有的部件位移與保體積保留並擴充；展示角度與模擬朝向分離。
### 3.4 圖鑑
- **構圖**：
  - 每種兵用「未裁切的大畫布」量出所有方向、動作、變體的聯集包絡，定一個固定縮放，播放中不自動縮放，留 10% 安全邊。
  - 標題區和角色區分開，槍尖不會再壓到名稱。
- **畫風一致**：連續轉身的直接繪製也套用同一個烘焙後處理（外框、漬洗、乾掃），轉身時畫風不突變。
- **檢視控制**：
  - 角度轉盤（左右步進，手把可用）、0.25 倍慢動作、逐格。
  - 攻擊對象假人和飛行區，讓投射物飛完整段。
  - 「完整棋子／近看細節」兩種視圖。
  - 假人演示和真模擬小劇場分開標示。
### 3.5 驗收（使用者和我們一起逐種確認）
- **工具**：
  - 需要真的繪圖（不能 headless），在本機有畫面時跑。
  - 每種兵輸出：360° GIF（正常＋慢速）、16 角度拼表、持物 4 倍特寫、攻擊逐格（含投射物飛到命中）、圖集對直接繪製的同角度比較（比輪廓、錨點、遮擋、時機，不要求逐像素相等）。
  - 輸出到 `docs/review/v150/units/`，每包附兵種 ID、版本、角度、動作、通過／問題編號。
- **範圍**：驗收母表列 20 種可部署、22 種繪製對象，小史萊姆、小骷髏、寶箱偽裝與攻擊變體都不能漏。
- **門檻**：使用者在圖鑑看每種兵的動畫並確認，是每個里程碑的驗收條件。
