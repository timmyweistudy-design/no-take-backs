# 新增語言成本評估（1.1.0 N2；只評估，不新增）

## 為什麼現在不加
- 四語（繁中、英文、簡中、日文）裡簡中與日文**都還沒有母語校對**（`docs/l10n-review/`；`python3 tools/gen/l10n_review.py status build/tmp/v140/l10n` 看進度）。再加一語只會多一份沒校對的翻譯。
- 份額不等於購買需求：Steam 硬體與軟體調查是自願填的介面語言（2026/10：英文 39.04%、簡中 21.98%、**俄文 10.14%**、西班牙文 4.83%、巴西葡萄牙文 4.46%；https://store.steampowered.com/hwsurvey/?l=english ）。上架後先看願望單與購買的地區分布再決定。

## 第一候選：俄文 — 成本盤點
| 項目 | 量 | 說明 |
|---|---|---|
| 介面字串 | 1,563 條，英文約 40,300 字元、7,500 個英文字 | `game/data/strings.csv`（以英文為翻譯來源，繁中對照） |
| 程式內二元陣列 | 92 條，約 900 字元 | `game/data/l10n_extra.csv` |
| 殘局／教學題名、提示、章節故事 | 英文約 10,200 字元 | `game/data/puzzles.json` 的 `*_en` 欄位 |
| 試煉、三考、幽靈、圖鑑 | 另計（各資料檔的語言欄） | 和殘局同一套欄位慣例（`L.field`） |
| 字型 | 西里爾字母：Fredoka（英數主字型）**沒有**；後備的源泉圓體（GenSenRounded）**有**（已查 cmap），所以不加字型也顯示得出來，但和拉丁字母的 Fredoka 風格不一致。要一致就加一個有西里爾的圓體（OFL）；子集由 `build_font.py` 產 | 授權要 OFL；版面檢查會量字形 |
| 版面 | 俄文平均比英文長約 15～30%（按鈕、木牌副標最容易擠）；字級表**不縮字** | 版面檢查 24 組 → 加俄文 100／125／150% 至少 27 組；英文 150% 擠的畫面要先修 |
| 校對 | 母語校對全文一次（`l10n_review.py export` 加語言） | 機器翻譯後一定要校；遊戲用語見 `docs/terms.md` |
| 程式 | `L.LANGS`／`SUFFIX` 加一項、設定頁語言按鈕（目前四顆一排，五顆要重排）、`localization.md` 流程 | 程式改動小 |

## 決策規則（上架後）
- 俄語區願望單＋購買 ≥ 10%，且簡中、日文校對完成 → 開始俄文。
- 否則看西班牙文／巴西葡萄牙文（拉丁字母，字型成本低，只有版面與校對成本）。
