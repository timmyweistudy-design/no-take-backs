## 2. 防止再犯：規則＋偵測器
### 2.1 規則（`docs/ui-layout-rules.md`，數值針對 1280×800）
- 間距階：4、8、12、16、24、32、48。
- R1 模態面板（有全螢幕遮罩）水平置中 ±1px；側欄、雙欄在程式宣告為例外。
- R2 標題緞帶置中於面板；緞帶完整下緣到首個內容：≥16 通過、12～16 警告、<12 失敗。
- R3 依附裝飾（書籤、緞帶尾、徽章）：依附邊貼齊（0～1px）、水平置中於宿主中線或宣告的角落。
- R4 按鈕群組外框中心＝容器中線 ±1；同組間距相等（±2）；雙按鈕同寬。
- R5 卡片：同一列卡片的圖示、標題、正文各自在同一基準線；多行正文靠左不各自置中。
- R6 面板高度貼合內容（內容佔 <50% 先報警告，再逐一決定縮高或列為例外）。
- R7 置中標題下的短副標置中；多行正文靠左。
- R8 子項不得超出容器內容區；可見裝飾距畫面邊 ≥16px（含焦點框外擴）。
- R9 彈窗：文字最下緣到按鈕列上緣 ≥12px（文字多就長高）。
- R10 同一欄的標題與操作列共用中線 ±1。
- 主按鈕高 48～52、一般 ≥44；大廳裡既有 36～40 高的小鈕（選牌、技能、沙盤技能）逐一列入：可見面維持、命中區擴到 44。文字上下各 ≥8。多行正文行距 1.5、中文每行 ≤40 字（參考 Xbox XAG 101、Material 8pt 網格）。
- R8 分開量「內容」與「依附裝飾」，合法的緞帶尾不算越界。
### 2.2 偵測器（`ui_base.gd` 探針＋`dev_main.gd _layout_report`）
- 介面：`with_container(id, role, rect, content_rect, draw_callable)` 包住每個語意容器（內部 push、畫、pop，提早 return 也不會漏收尾）；文字、按鈕自動歸屬目前容器；延後畫的書籤明指 `anchor_id`。`_tex_box` 的邊框、陰影只是畫法，不另當容器。
- 語意登記放在材質、簡化介面、缺圖分支之前（`_tex_box` 缺圖會提前 return）。覆蓋層打開時，底下畫面的容器資料也要清掉或按圖層過濾。
- 每幀檢查：容器堆疊清空、ID 唯一、父 ID 有效；未綁容器的文字／控制項直接報錯；每個畫面宣告必要角色與最低數量（只看「已登記數」抓不到漏掉整個面板）。
- 硬規則（FAIL）：R1、R2、R3、R4、R8、R9、R10；警告：R5、R6、R7。
- **反例測試**兩層：純矩形逐條驗規則代碼與元件 ID；實際繪圖驗探針有送資料。案例：偏心 2px、接縫 2px、緞帶下距 11px、按鈕間距差 3px、換行後壓鈕、焦點外框越界、漏父、重複 ID、零登記、堆疊失衡；每項配一個合法邊界與合法例外（避免「全部報錯也算成功」）。
- 先跑一次產出目前違規全表，本版修正清單＝偵測器全表 ∪ 人工看圖清單。卡片基準線只列警告時，人工看圖要特別核對幽靈頁這類正文高低不一。
