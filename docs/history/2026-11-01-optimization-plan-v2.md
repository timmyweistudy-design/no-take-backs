## 1. 騎兵打轉：根因與修法（P0）

### 1.1 重現（Claude 查證）
- 偵測器：40 tick 內走了 >3 格、但淨位移 <0.8 格，就算一次打轉。
- 跑 120 場訓練池：有騎兵的 102 場中抓到 **57 次**。

| 類型 | 次數 | 其中在上下邊緣 |
|---|---|---|
| A 繞翼途經點來回切換 | 34 | **28** |
| B 追擊移動目標時一步一停 | 8 | 2 |
| C 其他（人群推擠、目標切換等，待細分） | 15 | 1 |

### 1.2 根因（三方都確認）
- **A**：`_flank_waypoint()` 用「**現在**離途經點 <0.4 格」判斷「到過」。
  - 騎兵到了就改直衝，一離開 0.4 格又判定「沒到」而回頭。
  - 途經點的 y 被夾在地圖邊界（y=200），所以在邊緣來回。
  - 實例：tick 70～114 都在 x 9800～10000、y 200～370 之間來回，目標始終是同一個弓手。
- **B**：「要不要移動」看攻擊距離 0.75 格，「走到哪停」是 0.7 格。目標在移動時距離在門檻附近擺盪，每隔一個 tick 停一次。
- **A 的延伸**〔X〕：已經有途經點時，`need_move` 還是看敵人距離，不看導航階段。可能因此停在繞翼途中，不前進也不攻擊。

### 1.3 修法
1. **繞翼改成狀態機**〔X〕〔G〕：
   - 狀態：未規劃 → 繞翼中 → 已完成／已取消。
   - 距離 ≤0.4 格就**永久完成**這一次繞翼，同一次追擊不會因為離開而重來。
   - 換目標、目標死亡時清掉路線。嘲諷仍然優先。
   - 新欄位要納入 SHA-256 指紋與鏡像比對，規則版本升到 1.2.0。
2. **途經點不貼邊**〔G〕〔X〕：
   - 候選點先夾在 `EDGE+250` 以內。
   - 上下兩側比較實際可行空間、敵人密度與路程。
   - 兩側都不夠空就直接追。
3. **移動判斷看導航階段**〔X〕：繞翼中照路線走；敵人進入射程就結束繞翼開打，不能卡在未完成狀態。
4. **追擊遲滯**〔X〕〔G〕：
   - 距離大於攻擊距離才開始追，追到 `reach−150` 才停。
   - 沒超出外圈就不重新起步。
   - 實際攻擊仍嚴格用原本的攻擊距離。
   - **套用範圍**（分歧，採〔X〕）：先只改騎兵；用偵測器檢查其他兵種，有同樣症狀才擴用。〔G〕主張全部近戰一起改；弓手的站位不動。
5. **C 類 15 次先分類再修**〔X〕：
   - 把每一案整理成固定陣型＋tick＋追蹤紀錄（導航、選目標、推擠的原因）。
   - 分開「真的卡住」和「正常纏鬥」。
   - 確定是目標來回切換，才加「同級目標黏著」（〔G〕建議交戰中 15 tick 內不換目標，嘲諷與目標死亡除外）。
   - 暫不導入全場尋路。
6. **刺客的「繞到背後」目的地也可能落在場外**〔X〕：一起夾在合法範圍。

### 1.4 驗收
- 原本 120 場、57 次的軌跡要保存當回歸資料。
  - A、B 類在這些**固定案例**歸零。
  - 不保證所有正常追擊都零停步〔X〕，所以要定義分類規則與退步門檻：在新跑的 120 場裡，A 類必須是 0，B 類不能比 8 次多。
  - C 類逐案分類，正常纏鬥不算錯。
- 新增「原地沒進展」偵測〔X〕。
- 回歸案例：上下邊緣、角落、移動中的弓手、嘲諷切換、密集碰撞。
- 既有測試全過、100 組逐 tick 鏡像一致、**13 關殘局重新驗證**〔G〕。
  - 〔X〕：p1、p6 有盾兵、弓手和可選騎兵，直接牽涉繞翼；t3、p3、p8、p10 有敵方騎兵，會改變接敵與衝鋒時機。
  - 先回放舊的解法，檢查星級與解法種類，再決定要不要調關。
  - 驗證工具是隨機抽樣，「沒抽到解」不等於無解〔X〕。所以每關要存兩組標準解，作為固定回歸。
- 平衡守門：
  - 紅線照舊：剋制 10/10、競技池碾壓 <20%、勝方剩餘中位數 ≤30%、一局 35～75 秒。
  - 另外和修正前（24%／10%／42 秒）逐項比較，有明顯退步就算不過〔X〕。
  - 騎兵變正常後可能變強，反制庫也要重驗〔X〕。

## 3. 角色動畫（P1）

**原則**〔X〕：動畫全部是演出層，**不能偷偷延後傷害**。

**前搖做法：展示緩衝**（方向是〔X〕的，「2 tick」是 Claude 的細化，複查時補完整）
- 戰鬥畫面固定比模擬晚 2 tick（0.1 模擬秒）播放。模擬先跑，每個 tick 存一份狀態快照和事件，畫面依「展示時鐘」讀舊的那一份。這樣命中事件在畫面上發生前就知道，可以先演蓄力。
- **一起延後**：血量、死亡、音效、HUD、跳字都跟著同一個延後的 tick 走，不能只有動作延後。
- 開場先預填 2 tick；結束時把緩衝播完（排空）才進結果畫面。
- 變速、慢動作、頓格都改用同一個展示時鐘。現有的 `prev_pos` 插值不夠，要改成讀快照。
- 反擊在延後的命中那一刻立刻演出。
- 驗收：**接觸瞬間對齊事件 tick**，不是對齊牆上時鐘。兩邊玩家看到的都一樣，不影響確定性。

| 項目 | 做法（全部用程式繪製）〔G〕 |
|---|---|
| 三段式攻擊 | 共 0.32 秒：<br>・前搖 0.10 秒：身體後傾 12°、壓扁 0.90／拉長 1.08、武器往後拉 35°<br>・揮擊 0.07 秒：前撲 18°、武器揮到 +60°、新月刀光（alpha 0.7→0）<br>・後搖 0.15 秒：緩慢回正 |

| 兵種專屬 | 〔X〕：劍士蓄砍、盾兵踏穩、弓手拉弦、馬奔馳、刺客蹲身<br>〔G〕：<br>・騎兵衝鋒滿 3 格時前傾 15°、馬蹄噴土粒、槍尖金光<br>・盾兵頂住時盾放大 1.35 倍＋藍色六角波紋 |

## 4. 技能看得懂（P0／P1）

**現況**：被動技能只靠飄字，混戰時字疊成一團；有些效果（警覺、皮甲、絆馬）沒有獨立事件〔X〕。

**做法**：
- **事件補齊**〔X〕：
  - 一次攻擊可以帶多個效果標籤，例如「警覺＋命中」「皮甲減傷」，不再只有一個 kind。
  - 每個技能都要有圖示、短詞、音效，以及觸發原因。
- **專屬幾何特效，取代文字洗版**〔G〕：

| 技能 | 特效 |
|---|---|
| 破盾 | 目標頭上兩片裂開的盾往左右彈開（0.3 秒） |
| 頂住／暈眩 | 頭頂兩顆金色小菱形繞圈（持續 1 秒） |
| 背刺 | 背後紫紅交叉斬痕（0.25 秒） |
| 絆馬 | 馬腳一條白線，繃緊閃白後斷裂〔G〕複查 |
| 嘲諷 | 盾兵腳下擴散淡橘虛線圓（半徑 2 格），被吸住的敵人頭上冒 `!` |
| 警覺 | 弓手頭上亮起金色眼睛＋一條連向目標的極細金色瞄準虛線（0.25 秒）〔G〕複查 |
| 潛行 | 半透明（alpha 0.45）＋腳底暗紫殘影〔G〕複查 |
| 皮甲 | 受擊那一側浮出琥珀色半月形彈開弧光（外擴 10px、0.2 秒）＋箭矢偏折碎屑。小皮革紋太小、會被擋住〔G〕複查 |
| 拒馬 | 盾前方短槍陣剪影 |

- **飄字分級**：
  - 同兵種連續觸發，合併成一個有底色、有框的膠囊標籤。
  - 一般攻擊不跳字。
  - 垂直方向自動錯開 ≥18px。
- **難認程度**（〔G〕複查，Deck 1280×800、關閉閃白與震動）：從最難到最易依序是皮甲、警覺、絆馬／背刺、破盾、嘲諷／拒馬／頂住。前三名的特效已依此加強。
- **驗收**：
  - 關掉文字提示時，靠圖示能認出 5 種核心技能〔G〕。
  - 新玩家能說出八成以上示範的觸發原因〔X〕。
