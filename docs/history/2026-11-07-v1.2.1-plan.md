## 3. 方案

### P0 必修（8 項，64～80 人時）
1. **B1 結果緞帶摘要**：依語意斷行（原因｜戰力兩段），百分比不拆；緞帶高度與正文推進共用同一份量測（`game_result.gd`）。驗：英文 150% 無孤字。
2. **B2 小字**：3 處 `ts(12)` 改走字級表，實際字高 ≥12px@1280×800（Steam Deck 建議 12、最低 9）。驗：三字級截圖、量字高。
3. **F1 樣式快取**：alpha 量化（例如 16 級）＋快取上限與逐出，不能直接拿掉 alpha 鍵（會共用錯的透明度）；九宮格內容內距登記進探針。驗：反覆淡出後快取數穩定；內距不足會報違規。
4. **F2／F3 穩定性**：地塊烘焙用呼叫當下的固定鍵、失敗清掉 busy；Steam 鍵盤開啟失敗或取消時解除訊號。驗：烘焙中連切簡化介面；鍵盤拒開後重試只觸發一次。
5. **F4 設定遷移**：新音量欄位缺值時承接舊 `sfx`，保留舊靜音；設定欄位型別與範圍驗證；進度資料版本不因本機設定升級。驗：舊檔樣本（缺欄、錯型別、靜音、重複遷移）。
6. **F5 文字對比自動檢查**：
   - `_text` 登記轉墨後的實際 RGBA、裁切區與背景；背景依繪製順序合成，紙紋取最差點。
   - 線性 sRGB 算對比：一般字 ≥4.5:1，大字 ≥3:1（WCAG 大字＝24px 以上，或 18.66px 以上粗體，以 1280×800 顯示尺寸算）。
   - 有描邊的字，以描邊色對背景、字色對描邊兩者取較好的那個；描邊寬度要 ≥ 字級表規定值才算數。
   - 記錄背景覆蓋率：找不到背景＝不通過（不能因為漏測而報零違規）。
   - 停用元件另外列報（WCAG 豁免停用元件，不擋）。
   - 寫進 `dev_main.gd` 的版面違規，現有 `layout_check.sh` 直接擋。驗：已知對比樣本、透明疊色、未知背景三種測試。
7. **E1 四條音量**：設定加「介面音」「環境音」，共 4 條（音樂、音效、介面、環境），每條有試聽；拆掉介面音與音效的共用增益，避免重複衰減。驗：各軌單獨靜音互不影響；舊設定聽感相同。
8. **B3 捲動提示**：捲動區上下緣淡出，還有內容時才顯示「還有」箭頭；手把能捲到最後一行。驗：圖鑑筆記英文 150%、說明、清單。

**驗收矩陣擴充（P0 前置，Codex 擋路項）**：`layout_check.sh` 加跑簡化介面、色盲、停用、手把焦點四種狀態（兩語 × 三字級之外），貼圖缺檔直接失敗。

### P1 體驗（40～52 人時）
- **R1 焦點紙化、容器留木**：
  - 改紙：圖鑑老兵筆記改紙條；殘局／試煉「已過關」卡片改紙（未過關留木，進度一眼可見）；覆盤走勢圖區改紙。
  - 留深木：詳細數據、設定、戰績、自訂細項（紅藍條與白字在深底對比較好）。
  - 做法照 V1.2.0「墨色模式」（不動座標），彩色元件（徽章、條、停用態、金色焦點框）逐一配深邊；F5 通過後才算完成。
- **B4** 走勢圖時間標籤防撞（錯開或併進圖例列）。
- **B5** 中英混排：量「×2」「47.5s」「MVP 840」「12×7」基線與間距，修 NTB Latin／NTB Rounded 的落差。
- **B7** 大廳：未選中的預設也有短書籤耳；「卡牌」小兵列與「選牌」鈕水平對齊。
- **R2 按鈕狀態**：懸停加金亮邊（不位移）；手把焦點與滑鼠懸停同一樣式；按下加深內陰影（保留現有縮框＋下沉）。點擊判定維持立即，不加回彈與退場動畫。
- **R6 戰報**：隊章後加兵種短名；18px 圖集頭像要先通過辨識測試才換。
- **R5 敵情木牌**：擺陣時把紅旗底座擴成小木牌，只放公開資訊（敵方預算、兵數上限），不另加紙籤，保留屏風的神秘感。
- 詳細數據：長條數值位置規則一致（滿格時數字改放條外上方或統一放條外）。
- 戰績：未解鎖成就顯示解鎖條件；已解鎖、未解鎖框線對稱。
- 英文 150%：兵池 Beats／Fears 間距；覆盤藍紅標題間距（第 3 輪 Antigravity 補入）。
- **E2** 真人盲聽（介面音會不會太吵、哪些重複感高）＋峰值量測；短音效不硬套同一 LUFS。

### P2 加分與上架軌（28～40 人時，獨立交付）
- **R3 勝利光芒**：緞帶後方一次性放射光＋燕尾外 6 顆金星 0.6 秒；畫在緞帶下、限燕尾外、簡化特效時關。
- **R4 標題**：雙劍尺寸不變、加亮金描邊；右下兵種列加木架。
- **F6 圖示預烘**：先量；若圖示占繪圖時間明顯才烘成貼圖。
- **G1 商店素材**：小膠囊縮到 120×45 仍可讀（標誌幾乎填滿）；截圖改 1920×1080 全螢幕渲染，8～12 張、前 3 張最強。
- **G2 手把字形**：PS 圈／三角改向量符號；Deck 用 Deck 或 Xbox 名稱；不是當前輸入的鍵鼠字形不出現。
- **G3 本地化前置**：抽出 `replay_view.gd` 等處的中英二分文案；簡中／日文字型分區子集與缺字檢查、禁則；不含翻譯本身。依據：Valve 2024 帳號資料簡中約 33.7% 略高於英文，Valve 建議先中日韓。

## 4. 實作順序（Codex 第 3 輪）
1. 固定基準：完整檢查，核對 FINGERPRINT。
2. F4 遷移（舊靜音、缺欄、錯型別、重複遷移測試）。
3. F1～F3（快取上限、切換簡化介面、烘焙失敗重試、鍵盤拒開／取消測試）。
4. E1（四軌各自靜音與試聽互不干擾，共用增益已拆）。
5. 驗收矩陣擴充＋F5＋九宮格探針（已知對比樣本、透明疊色、未知背景必敗）。
6. B1～B3（百分比不拆行、Deck 字高、手把到末行）。
7. P1 紙化與排版：跑完整狀態矩陣，版面與對比都零違規。
8. P2 與發版：簡化特效關閉慶祝、字型覆蓋、同機 p95 回歸；最後真人試玩。

## 5. 驗收
- 自動：兩語 × 三字級 × {一般、簡化介面、色盲、停用、手把焦點} 全截圖；版面 0 違規、對比 0 違規（停用另列）、貼圖缺檔 0；FINGERPRINT 與數值摘要不變；同機繪圖 p95 ≤ V1.2.0。
- 指定截圖（Antigravity 第 3 輪）：圖鑑老兵筆記、殘局／試煉過關卡、覆盤走勢圖（R1）；結果走勢圖右上（B4）；大廳頂部與卡牌列（B7）；戰鬥底部戰報（R6）；擺陣右側紅旗（R5）；詳細數據刺客滿條（數值位置）；戰績成就區（條件與框）；英文 150% 兵池與覆盤標題（間距）；設定聲音分頁（E1／E2）。
- 真人：3 人試玩，問「哪裡還像電腦做的」；E2 盲聽紀錄。

## 6. 風險（Codex 第 3 輪）
1. 對比探針漏算背景 → 記錄覆蓋率，找不到背景就判失敗。
2. 音量遷移破壞舊靜音 → 舊檔樣本加各軌單獨回歸。
3. 字型與驗收矩陣膨脹 → G3 獨立交付；P0／P1 先封版。

## 7. 工時
P0 64～80、P1 40～52、P2 28～40，合計約 132～172 人時（Codex 第 3 輪估，含測試工具與回歸；Claude 第 2 輪原估 96～136 偏緊）。

## 8. 不做
- 全頁紙化（Antigravity 第 2 輪自己也反對：全亮失去視覺錨點，紅藍條在深底對比較好）。
- 按鈕回彈與退場動畫（立即模式關閉後畫殘影不安全，也可能延遲輸入）。
- 改玩法、數值，新內容，預告片剪輯（另案）。
- 雙劍放大（改加亮邊）。
