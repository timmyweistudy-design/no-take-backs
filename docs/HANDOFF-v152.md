## 4. 防止再犯：規則＋偵測器（三方共識：不做就會再犯）
### 4.1 規則文件 `docs/ui-layout-rules.md`（新寫）
- 間距階 4／8／12／16／24／32／48。
- R1 模態面板（有全螢幕遮罩）水平置中 ±1px；側欄、三欄畫面宣告例外與自己的基準欄。
- R2 緞帶置中於面板；緞帶完整下緣到首個內容 ≥16 通過、12～16 警告、<12 失敗。
- R3 依附裝飾（書籤、緞帶尾、徽章）貼齊依附邊 0～1px，水平位置照宣告（置中或指定角落）。
- R4 按鈕群組外框中心＝所屬欄中線 ±1；同組間距差 ≤2；雙按鈕同寬。
- R5 同列卡片的圖示／標題／正文各自同一基準線（警告）；多行正文靠左。
- R6 內容佔面板可用高 <50% 警告（再逐一決定縮高或列例外）。
- R7 置中標題下的短副標置中。
- R8 子項不超出容器內容區；可見裝飾距畫面邊 ≥16（含焦點框外擴）；內容與依附裝飾分開量。
- R9 彈窗文字最下緣到按鈕列 ≥12。
- R10 同一欄的標題與操作列共用中線 ±1。
- 主按鈕高 48～52、一般 ≥44；大廳既有 36～40 的小鈕可見面不變、命中區擴到 44。多行正文行距 1.5、中文每行 ≤40 字（參考 Xbox XAG 101、Material 8pt 網格）。
### 4.2 偵測器（`scripts/ui/ui_base.gd` 探針＋`tools/dev_main.gd` `_layout_report`）
- 介面：`with_container(id, role, rect, content_rect, draw_callable)` 包住每個語意容器（push→畫→pop，提早 return 不漏收尾）；文字、按鈕自動歸屬目前容器；延後畫的裝飾（書籤）明指 `anchor_id`；`_tex_box` 邊框、陰影只是畫法不另算容器。
- 語意登記放在材質／簡化介面／缺圖分支之前（`_tex_box` 缺圖會提前 return）；覆蓋層打開時清掉或按圖層過濾底下畫面的容器資料。
- 每幀檢查：堆疊清空、ID 唯一、父 ID 有效；未綁容器的文字／控制項報錯；每個畫面宣告必要角色與最低數量（**漏登記守衛**）。
- 硬規則 FAIL：R1、R2（<12）、R3、R4、R8、R9、R10；警告：R2（12～16）、R5、R6、R7。
- **反例測試**兩層：純矩形逐條驗規則代碼與元件 ID；實際繪圖驗探針有送資料。案例：偏心 2px、接縫 2px、緞帶下距 11px、按鈕間距差 3px、換行壓鈕、焦點外框越界、漏父、重複 ID、零登記、堆疊失衡；每項配合法邊界與合法例外。
- 先跑一次產出違規全表；**本版修正清單＝偵測器全表 ∪ §3 人工清單**。
