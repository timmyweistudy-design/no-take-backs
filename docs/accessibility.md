# 無障礙對照（V1.0.0 S1）

依 [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/)（基本／中級）逐條對照；本作是回合外擺陣＋自動戰鬥、沒有語音與劇情字幕、沒有時間壓力（極速賽除外），所以聽覺、即時反應類多半「不適用」。Steam Deck 的文字與輸入要求另見 `docs/release/steam-setup.md` D 節。

| 準則（GAG） | 等級 | 狀態 | 本作做法 |
|---|---|---|---|
| 可以改鍵（鍵盤、手把） | 基本 | ✓ | 設定「操作」頁改鍵；按住確認也走改鍵（V1.6.1） |
| 震動可以關 | 基本 | ✓ | 震動強度 0～100（新安裝 25%） |
| 互動元件夠大、間距夠 | 基本 | ✓ | 小按鈕可見面不變、點擊區 44（`_btn_small`）；版面檢查查點擊框 |
| 文字夠大、可放大 | 基本 | ✓ | 字級 100／125／150%；字級表最低 14、不縮字；V1.0.0 版面檢查加「字形實高 ≥ 9px」（Deck） |
| 文字對比夠 | 基本 | ✓ | 截圖取樣量對比（V1.2.1），描邊＋浮雕；檢查不過算違規 |
| 不只靠顏色傳達 | 基本 | ✓ | 色盲模式（隊伍形狀：藍圓、紅菱）；狀態小牌是字不是色 |
| 不要快速閃爍 | 基本 | ✓ | 閃白強度可調（新安裝 50%）；殘血框約 1 Hz 呼吸；減少動態時不閃 |
| 遊戲速度可調 | 中級 | ✓ | 0.25～8 倍；任何時候可暫停、跳轉、時光機 |
| 支援多種輸入 | 中級 | ✓ | 滑鼠、鍵盤、手把（Xbox／PS／Switch 圖示）、觸控（長按＝右鍵、捏合縮放）；觸控與 Deck 未實機驗 |
| 介面可客製 | 中級 | ✓ | 設定七頁；簡化介面（去材質）；提示停留可手動關 |
| 一鍵無障礙預設 | 中級 | ✓ | 三個一鍵預設（可疊加、可撤回） |
| 文字放大鏡 | 中級 | ✓ | 滑鼠跟游標、手把跟焦點按鈕 |
| 按住確認（防誤觸） | 中級 | ✓ | `hold_confirm` 0.6 秒 |
| 音量分開調 | 基本 | ✓ | 主音量＋音樂、音效、介面、環境四條；夜間模式（壓縮）、單聲道 |
| 字幕 | 基本 | 不適用 | 沒有語音、沒有劇情對白；AI 台詞是畫面文字 |
| 時間壓力可關 | 中級 | 部分 | 一般模式擺陣不計時；極速賽是計時玩法本身（只在擺陣計時） |
| 暗色地圖上的隊伍辨識 | （本作補） | 待驗 | 隊伍圈在暗色地塊（熔岩、迷霧）對比靠版面截圖目視；Gemini v100 r5 建議的「依族群黑白圈」不採（要分的是隊伍） |

**沒做、理由**：螢幕閱讀器（全自繪介面，沒有 Control 樹，成本大；1.0.x 再評估）；單手模式（手把已可單手完成多數操作，未實測）。
