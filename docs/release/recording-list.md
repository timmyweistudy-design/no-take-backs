# 實機錄影清單（1.6.0 B19；P8.4）

給實機（Windows 桌機或 Steam Deck）錄商店影片、預告片素材用。**錄影要人在機器前操作，Claude 不錄**（長時間可見視窗與帳號狀態的動作由你來）。

## 共通設定
- 解析度 1920×1080（Deck 1280×800 照原生），全螢幕，60 fps，音效 100、音樂 60。
- 設定：字級 100%、簡化介面關、減少動態關、減少特效關、跳字「合併」。
- 每段錄 8～15 秒，前後各多留 1 秒（剪輯用）；滑鼠游標錄進去（擺陣要看得到手）。
- 截圖模式的商店預設（`--shot=<夾> --shot-fixed --store`，見 `tools/dev_main.gd` `_shot_store`）是靜態圖；錄影用同一組陣型對照：藍＝訓練陣第 3 個、紅＝訓練陣第 10 個（鏡像），前排各往後一欄。
