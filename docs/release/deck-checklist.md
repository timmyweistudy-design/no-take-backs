# Steam Deck／觸控 實機驗收清單（V1.4 #18）

> 程式端已做：觸控點擊＝左鍵、長按 0.5 秒＝右鍵（擺陣時拿掉兵，會短震一下）、雙指捏合縮放戰場（1～2 倍，新的一場回全景）、觸控板捏合同樣可用；1280×800 是遊戲原生解析度，最小字級 14px（大於 Deck 建議的 12px）；手把流程（PADWALK）每次版面檢查都會走過標題與各畫面。
> 這份清單要在真的 Deck 上跑，模擬器測不到。

## 1. 安裝與啟動
- [ ] 從 Steam（Proton 或原生 Linux 版）啟動，首頁出現時間 < 10 秒
- [ ] 全螢幕 1280×800，沒有黑邊、沒有被裁切
- [ ] 待機回來（按電源鍵睡眠再喚醒）畫面、聲音都正常

## 2. 手把（不碰螢幕）
- [ ] 標題每顆按鈕都走得到（十字鍵／左搖桿），A 確定、B 返回
- [ ] 擺陣：選兵、放兵、拿掉、開戰都能只用手把完成
- [ ] 遊戲間四張卡、塗裝室六列色票、宿敵戰記、接力殘局、競猜、輪抽都能用手把操作
- [ ] 戰鬥中暫停、重播、時光機、錄 GIF 都按得到
- [ ] 按鍵提示圖示是 Steam Deck／Xbox 樣式，不是鍵盤

## 3. 觸控
- [ ] 點按鈕有反應、沒有誤觸到旁邊的按鈕
- [ ] 擺陣：點格子放兵、拖曳搬兵、長按拿掉兵（會短震）
- [ ] 戰鬥與重播中雙指捏合放大／縮小，放開後停在那個倍率
- [ ] 文字輸入框（貼上代碼）會叫出 Steam 螢幕鍵盤（Steam＋X）

## 4. 可讀性
- [ ] 文字 100%、125%、150% 三種在 7 吋螢幕上都看得清楚
- [ ] 簡中、日文切換後字型正常（不是方塊、不是系統字）

## 5. 效能與電量
- [ ] 48 隻兵大混戰時維持 60 fps（設定可開效能顯示）
- [ ] 玩 30 分鐘機身溫度與耗電正常（參考：約 8～12 W）

## 6. Steam 驗證
- [ ] Steamworks 後台「Steam Deck 相容性」送審（要由你在後台操作）

發現問題時請附：畫面截圖、在哪個畫面、用手把還是觸控。

## V1.6.0 新增（實機要看的）
- 手把：確認框開「按住確認」時，按住 A 0.6 秒才執行；點一下不會執行（按鈕上有進度條）。
- 手把：擺陣資訊帶右邊的「射程」「標記」「實驗簿」小鈕要能用焦點走到並按下；標記模式下 A 點我方兵會加號碼。
- 觸控：殘局出題台的小棋盤（36px 格）在 Deck 螢幕上點得準不準；兵種調色盤 92×48。
- 觸控：差一子教練、分享面板、裂隙、一陣三考、極速賽的按鈕都在 44px 以上。
- 文字放大鏡只跟滑鼠（手把模式不顯示）；Deck 用觸控板當滑鼠時要看得到。
- 雙人接力遠征：同一台 Deck 兩人輪流，交接畫面的「準備好了」用 A 能按。
- 聲音：落子時的木頭聲、倒下的木座聲、膠著時的低鼓，在 Deck 喇叭上會不會太大聲（盲聽頁 `docs/playtest/listen.html` 已加入）。
