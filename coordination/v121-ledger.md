# V1.2.1 裁決紀錄（方案階段，未實作）
- 方案：docs/2026-11-07-v1.2.1-plan.md。三輪：v121-r1（獨立提案）、v121-r2（互評）、v121-r3（定稿）。
- Ruling R1：焦點紙化、容器留木（只紙化老兵筆記、已過關卡、覆盤走勢圖）— Antigravity 第 2 輪改口反對全面紙化、Codex 擔心重排與彩色元件 — 代價：深木與紙頁仍混用。
- Ruling R2：按鈕不加回彈與退場；只補懸停亮邊、焦點一致、按下內陰影 — 立即模式關閉後畫殘影不安全，也不能延遲輸入 — 代價：動態感有限。
- Ruling R3：勝利慶祝只做 P2 原型，限燕尾外、緞帶下層、簡化特效關閉 — Codex 擔心遮字 — 代價：慶祝感較弱。
- Ruling R4：雙劍尺寸不變、加亮邊 — 英文 150% 標題框已滿 — 代價：縮圖辨識只靠亮邊。
- Ruling R5：敵情資訊整合進紅旗木牌，只放公開資料 — 不破壞屏風的神秘感、不洩露隱藏資訊 — 代價：資訊量少。
- Ruling R6：戰報先加兵種短名，頭像要過辨識測試 — V1.2 的 14px 頭像糊成一團 — 代價：戰報變長。
- Ruling R7：樣式快取 alpha 量化＋上限，不直接刪 alpha 鍵 — 刪鍵會共用錯的透明度 — 代價：極少數淡出層級被合併。
- Ruling R8：對比檢查找不到背景就判失敗、停用元件另報 — 避免漏測報零違規；WCAG 豁免停用元件 — 代價：初期可能多出要補登記的背景。
- 採用 Codex 第 3 輪兩項擋路修改：驗收矩陣加簡化／色盲／停用／焦點與缺圖失敗；F5 判定規格（大字門檻、描邊、覆蓋率）寫明。
- 工時採 Codex 第 3 輪估 132～172 人時（含測試工具）。
- 查核不採：擺陣頂列碰撞、圖鑑分頁撞燕尾（截圖查無）；兵池圖示「重疊」降為間距問題；「按鈕沒有縮放」不實。
