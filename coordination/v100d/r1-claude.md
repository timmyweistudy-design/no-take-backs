# 第 1 輪 Claude（主持＋產品／內容）獨立提案

- Steam Deck 相容性：1280×800 下最小字 9px、建議 12px；畫面上的按鍵圖示要跟輸入裝置一致（Deck／Xbox）；要打字時須用 Steamworks API 叫出螢幕鍵盤，或自備手把可用的輸入。https://partner.steamgames.com/doc/steamdeck/compat
- 成就圖示：256×256 PNG（可小但建議大）、方形；未解鎖灰階可由後台自動產生。https://partner.steamgames.com/documentation/bootstrap_achieve
- Steam 語言：2026 年 6 月英文約 38%、簡中約 24%、日文約 2.6%（次級資料，且春節月簡中會暴衝）。https://www.steampageanalyzer.com/blog/steam-localization-languages 、https://www.gamingonlinux.com/2026/10/steam-survey-for-september-2026-shows-a-drop-in-linux-with-simplified-chinese-rising/
  → 簡中的份量遠大於日文：簡中母語校對優先於日文。
- 上架：Coming Soon 頁要提早數週～數月累積願望單；每款遊戲只能參加一次 Next Fest，需要公開可玩的試玩版、審核要提前約 3 週。https://www.steampageanalyzer.com/blog/steam-next-fest-checklist 、https://presskit.gg/field-guides/steam-next-fest-guide （行銷部落格，日期以 Steamworks 為準）
- 定價：同類獨立自動對戰多在 US$2～15；一份定價指南說乾淨的 14.99 首發中期優於 9.99 重折扣（意見，非數據）。https://gtstu.com/steam-indie-game-pricing-strategy/
- 無障礙：Game Accessibility Guidelines 分基本／中級／進階，基本含改鍵、震動開關、互動元件夠大；中級含多種輸入、遊戲速度可調、介面可客製。https://gameaccessibilityguidelines.com/ ；Xbox 準則可當測試清單。https://learn.microsoft.com/en-us/gaming/accessibility/guidelines

## 產品判斷
1. **內容量已經超過同類獨立作品**（120 殘局、30 試煉、20 三考、13 種模式、22 兵）。1.0.0 的問題不是「少」，是「入口多、說明散、沒人試過」。所以方向是：**收斂入口、統一說法、補真人驗證管道**，新增內容只做讓既有內容更好懂的。
2. **入口重整**（提案）：主畫面保留五木牌，但「挑戰」8 張卡分兩組：常駐（殘局、試煉、每日、極速賽）／每週輪替（每週棋盒、裂隙、三考精選）；接力遠征併進遠征的「雙人」選項；迷霧併進對 AI 的「規則變化」；出題台、工坊碼、挑戰碼併成「創作」。要 Antigravity、Codex 攻擊。
3. **學習路線**：教學 3 關 → 剋制 ▲▼ 互動 → 第一個殘局章 → 建議下一步。把 V1.6.1 導覽變成這條路線的最後一站，不另開入口。
4. **說法統一**：「娛樂／實驗／未驗證」三種徽章意思不同，玩家看不懂 → 正式版只留「排名認證」與「自由玩法」兩級，說明一句話。
5. **真人驗證管道**是 1.0.0 的硬缺口：試玩回報已有（漏斗＋回報 json），缺的是「怎麼收」：試玩版內「回報」→ 開瀏覽器到表單（不上傳、只複製）；docs 寫試玩邀請流程。
6. **商店素材**：膠囊、截圖、30 秒預告腳本已有程式版；正式版要成就圖示 37 張（256×256，用兵種頭像＋徽章框程式生成）、商店頁四語、更新說明「1.0.0 包含什麼」。
7. **簡中校對優先於日文**（市場份量）；英文文案找母語者看「翻譯腔」。
8. **砍或延後候選**：相鄰陣法（4 組 +8%，平衡樣本不足）、迷霧（獨立入口）、雙封蠟戰書（跟雙人禁牌重疊）——第 2 輪請其他兩方評估是否保留。

## 對清單的逐項（產品面）
- M1 教學：併學習路線（中）。M2 對 AI：結果頁說「這位對手的習慣」一句（小）。M3 雙人：先手量測做不出來 → 預設改「暗擺」降低先手問題？要辯（小）。M4 遠征：結束總結共用接力的總結頁（小）；整場重播碼（中）。M6 殘局：每章完成給一張「章節印章」貼紙（現有貼紙系統，小）。M8／M9：沒有 Steam 時入口說明改「離線時打本地紀錄」（小）。M10 遊戲間：五個玩法一致的「規則卡」（小）。M11～M14：題庫、異變、三考門檻不動，只改說明（小）。M17 試玩版：照 Next Fest 需求檢查（中）。
- R 結果頁：資訊分「勝負／三星／原因與教練／分享」四層，預設只展開前兩層（中）。
- W：上架清單文件化；成就圖示生成工具（中）；價格提案 US$9.99～14.99 留給使用者決定。
- N：第一場時間（從開遊戲到第一次按「開戰」）進漏斗，當 1.0 指標。
