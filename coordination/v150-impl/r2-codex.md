1. **高｜還原未落盤仍顯示成功。** `scripts/ui/screens/game_menus.gd:745`：忽略 `Save.save_data()` 結果，寫入失敗仍提示完成；若載入時已有 `data_locked`，此呼叫甚至直接略過寫入並回傳成功（`scripts/game/save.gd:422`）。後者還原後繼續玩的進度也不會保存，重啟仍讀原檔。

2. **高｜還原身分驗證仍不足。** `scripts/game/save.gd:452`：只要求存在版本欄；例如 `{"version":1}`，甚至 `{"schema_version":"錯誤"}` 都可通過。選取這類 JSON 備份並確認後，會被補成空白進度，覆寫目前資料；第一輪的身分驗證問題只修了一部分。

3. **高｜同秒備份會覆蓋復原副本。** `scripts/ui/screens/game_menus.gd:714`：檔名精度只有秒，並以 `WRITE` 開啟。若同一秒連續清除不同分類，第二次自動備份會覆蓋第一次清除前的完整進度，失去原始復原點。

4. **中｜已全破幽靈的老玩家無法取得新成就。** `scripts/ui/screens/game_modes.gd:1727`：`GHOST_ALL` 檢查放在「首次打敗該名將」分支內。更新前已打敗全部名將者，再打任何一位都不會進入檢查，正常遊玩無法解鎖。

6. **中｜還原／全部清除後，塗裝仍沿用舊狀態。** `scripts/ui/screens/game_menus.gd:744`、`:787`：替換 `Save.data` 後沒有重新套用 `_paint_apply()` 及更新圖集。備份塗裝不同、或清除全部資料時，畫面與塗裝室仍顯示舊配色；後續改色還可能把舊配色其餘欄位寫回。

7. **中｜醫者近戰被當成補血飛行物。** `scripts/ui/battle_view.gd:219`：通用遠程判定包含醫者所有傷害攻擊。隊伍只剩支援兵、醫者開始近戰時，長緩衝局會提早出手並向敵人發射綠十字，實際命中卻是近戰傷害。BONK 排除修正沒有涵蓋這個同類情況。
