# V1.5.0 實作裁決（三方：Claude、Codex、Antigravity）

## 第 1 輪（M1＋M2 前半審查，r1-codex.md、r1-agy.md）

已修：
- 自動備份失敗仍繼續還原／清除 → 備份回傳成敗，失敗就停（Codex #1）。
- 還原不驗證身分與版本 → `Save.restorable`：要有版本欄、不能比這版新（Codex #2）。
- 投彈兵貼身敲擊被當成飛行物 → BONK 不登記；`proj_phase` 只提早「真的有飛行物」的那幾發（Codex #3）。
- 施放者飛行途中陣亡，飛行物消失 → 陣亡者已離手的飛行物照畫到命中（Antigravity #1）。
- 命中佇列只留 4 筆，8 tick 緩衝下會擠掉還在飛的那發 → 留 8 筆（Antigravity #1）。
- 跳轉沒清 `proj_tgt`、`alt_hit` → 清掉（Antigravity #1）。
- 圖鑑慢動作切換會跳幀 → 改成累積播放時鐘（Codex #8）。
- 圖鑑出手看不到飛行物 → 遠程出手時畫出箭／炸彈／法球／補血（Antigravity #9）。
- 匯入設定碼、還原備份沒有確認 → 通用確認框，匯入先列出會改幾項、哪幾項（Codex #5、Antigravity #7）。
- 預設組合、匯入逐項寫檔、沒有套用副作用 → `Save.set_settings` 一次寫檔＋`_apply_all_settings`（Antigravity #6）。
- 最小化還原把幀率上限洗成無上限 → 還原時重新套用設定（Antigravity #4）。
- 設定說明欄的滑鼠判定位置與畫面錯開、手把移焦點不更新說明 → 共用 `_settings_row_y`，焦點也帶說明（Antigravity #3）。
- 低操作負擔預設沒有「提示手動關閉」→ 提示停留新增「手動關」（點一下收起），預設組合改用它（Codex #9）。
- 死區預設、步進不符方案 → 5～40%、每格 5%、預設 20%；圖鑑捲動、自由擺陣游標也照設定（Codex #10、Antigravity #12）。
- 音量只有 5 檔 → 每格 5%（Codex #10）。
- 新安裝的震動、閃白預設 → 25%、柔和 50%；老玩家照原本開關（開＝100%）不改手感（Codex #10）。
- 鼓手鼓槌沒有手、骷髏法師骨棒浮空、弓箭手握弓的手懸在弓肚 → 補握持（Codex #11、Antigravity #10）。
- 狂戰士遠側斧頭疊在胸口 → 遠側斧改在身體之前畫（Codex #12、Antigravity #10）。

裁決（不照建議做，或縮小範圍）：
- Ruling：圖鑑角度盤只轉半圈（右側面→正面→左側面，9 格），不做背面 —— 22 種背面要逐一重畫（髮型、披風、箭袋、盾背），工作量等於重畫一輪角色；原本 16 格會讓 90°～270° 重複正面，等於假裝有背面 —— 錯了的代價：玩家看不到背面，之後要另開一輪補。
- Ruling：手動軍令局（緩衝 2 tick）不提早出手 —— 緩衝拉長會讓下軍令的反應慢 0.3 秒；這種局遠程維持「快箭」示意 —— 代價：這種局仍是先扣血、箭後到。
- Ruling：戰場上轉身途中出手先轉回側面（不當幀直接繪製）—— 圖集只有側面的攻擊幀，當幀直接繪製會讓大混戰每幀多畫數十隻 —— 代價：轉身中出手會跳一下。
- Ruling：暫停選單不做「重開」—— 勝負在擺陣時就定了，重開＝看完結果再改陣；改放「直接看結果」—— 代價：與方案字面不同。
- Ruling：主畫面第二層用覆蓋面板，不在右側原地展開 —— 右側是背景示範戰場，原地展開在 150% 字級放不下五張卡 —— 代價：多一層遮罩。
- Ruling：「清除資料」的分類維持教學／殘局星數／戰績宿敵／全部；方案的「快取、未收藏重播」目前沒有對應的存檔欄位 —— 代價：沒有。
- 誤報：Antigravity #3 說 `_settings_close`、`_pause_resume`、`_open_pause_menu` 未定義 —— 定義在 game_menus.gd（同一條繼承鏈），測試 `test_pause_menu_v150` 會呼叫。
