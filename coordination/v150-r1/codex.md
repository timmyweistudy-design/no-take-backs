**入口歸屬原則**

- 每個功能有一個正式歸屬；其他位置可放捷徑，開啟同一份資料。
- 「我的陣型」可從收藏與大廳進入，避免出現兩套存檔。
- 「匯入代碼」也可出現在對戰、殘局頁；先辨認代碼類型，再開啟正確預覽。
- 每日、每週移出遊戲間，集中到挑戰，顯示日期及完成狀態。
- 宿敵、塗裝不再藏在戰績的次入口裡。

**主畫面構圖**

- 左側固定五顆按鈕。
- 右側保留沙盤示範，下方棋子展示可直接進圖鑑。
- 右側只放一張情境卡：新玩家是教學；有續局是繼續遠征；其他情況是最近玩法。
- 情境卡不搶初始焦點、不自動彈出，也不使用輪播廣告式切換。
- 示範戰鬥可關閉，或改成靜態棋桌。

**第一次與老玩家**

| 情況 | 預設行為 |
|---|---|
| 第一次啟動 | 先顯示可略過的語言、字級、無障礙快速設定，再到主畫面 |
| 尚未完成教學 | 右側顯示「學會擺第一場」，可直接進正常對戰 |
| 已完成教學 | 初始焦點停在「開始對戰」；右側顯示最近玩法 |
| 有遠征續局 | 顯示站數、軍隊摘要與「繼續遠征」 |

不依玩家身分重排五顆按鈕，讓操作位置可以記住。

**手把動線**

- 十字鍵／左搖桿上下選主按鈕，確認進入，返回退一層。
- 肩鍵切換子分頁；返回後恢復原焦點與捲動位置。
- 焦點框同時使用外框、亮度及小指標，不能只有顏色差異。
- 子頁第一焦點放主要動作；續局與新局有不同標籤，避免誤覆蓋。
- 開始對戰 → 快速對 AI → 擺陣，最多兩次確認抵達擺陣頁。

**觸控動線**

- 以 1280×800 為驗收基準，主要觸控目標至少約 48×48 邏輯像素。
- 重要功能都有可見按鈕，長按只是替代操作。
- 擺陣提供「選棋子→點位置→確認」，拖曳可選。
- 雙人交接使用整頁遮罩與「已交給對方」確認，遮罩期間禁止長按穿透。
- 捏合縮放之外，提供縮放＋／－與重置鏡頭。

**設定頁新結構**

左側分類、中央選項、右側說明與即時預覽；小畫面改成「分類頁→選項頁」，不硬塞三欄。

1. 常用
2. 畫面
3. 介面
4. 聲音
5. 操作

7. 無障礙

另放明確入口 **「對戰規則：影響本局」**，開啟大廳規則編輯器。

**設定頁本身必備**

- 搜尋名稱、說明與同義詞，例如「晃動」能找到鏡頭震動。
- 常用頁是原選項的捷徑，不另外儲存一份。
- 顯示「已修改」、預設值、是否立即生效。
- 每項、每分頁、全部三種重設範圍。
- 搜尋結果顯示所在分類，手把可直接跳到該列。
- 布林值使用開關；枚舉使用分段選擇／清單；音量使用滑桿，改掉所有值都靠左右箭頭輪轉的做法。
- 顯示設定修改後即時預覽；解析度／視窗模式使用限時復原。
- 規則修改在開戰前確認，戰鬥中不能改已凍結的本局規則。
- 所有預設組套用前列出差異，允許撤回。

**作用標記**

| 標記 | 意義 |
|---|---|
| **顯** | 顯示、聲音、輸入方式或資料管理；相同陣型、規則與軍令紀錄下，不改模擬結果 |
| **局** | 影響組局、部署合法性、AI 或系列流程；寫入規則碼／對局中繼資料 |
| **戰** | 改戰鬥計算；寫入規則碼、重播資料及適用的模擬指紋 |

輸入方式、觀戰速度可能改變真人下軍令的時機；**真正執行的軍令 tick 必須記錄在重播**，不能只存玩家的操作偏好。

**時間同步的實作選擇**

上述較長飛行時間**超過目前 0.1 秒展示緩衝**，不能只改特效長度。

建議分兩條：

- **純自動對決、重播、圖鑑真模擬**：展示緩衝擴至約 8～10 tick，容納前搖與飛行；血條、死亡、音效、戰報事件一起使用展示時間。
- **有即時手動軍令的對局**：先維持短緩衝，使用約 0.05～0.10 秒快速飛行。不能直接把長緩衝套上去，增加操作延遲。

- 使用展示 tick 與插值，不用彼此獨立的牆鐘計時器。
- 飛行終點取實際命中時的目標位置；保留足夠快照，不能只查目前畫面位置。
- 暫停時飛行停住，倍速時同步加速，跳轉後清除並重建。
- 第一擊缺少完整前置時間時縮短演出，不在開戰前憑空飛彈。
- 同一發炸彈的波及事件不能生成多顆彈。
- 減少特效仍保留物件本體、路徑方向及必要命中提示。

**C2．手持物：建立共同握持畫法**

現在的「像被裁掉」至少有三個不同來源：物件本身沒畫完整、手部遮擋順序不對、圖鑑構圖越界。應分別修。

**共同部件**

- 武器局部座標包含：握點、柄尾、護手、刃根／工具根、尖端、發射點。
- 手分成掌後片與手指前片。
- 一般順序：遠手／掌後 → 握柄 → 掌前與手指 → 護手、刃身；實際順序由角度調整。
- 手指以少量弧線與指節塊面包住柄，不需要寫實五指。
- 握柄被手蓋住的部分合理隱藏，但柄尾、護手與刃根要讓人能判讀連接。

**逐類修正**

- 劍士：補柄尾、握柄、護手，避免刀刃直接插進掌心。
- 刺客：兩把短刀分別有握點；遠手與近手不能共用固定最前層。
- 騎兵／長槍兵：槍桿在握點分前後段，手指覆在桿前；刺擊時手與槍一起移動。
- 弓箭手：弓把、握弓手、拉弦手、箭與弦各自有錨點，拉弦時不能脫離。
- 投彈兵：火罐在離手前跟手，離手後從手部層移除。
- 醫者：手包住杖身，十字與杖頂不隨轉身穿頭。
- 鼓手：鼓槌有短柄尾；敲擊終點落在鼓面。
- 狂戰士：兩柄斧的斧頭、柄與手分離，側身時遠斧可被身體遮住。
- 法師：手托住書脊／底邊，書頁朝向與胸部朝向一致。
- 巫毒娃娃與骷髏：針、骨製工具也走同一握持規則。

驗收包括待機、前搖、命中、收招與各方向，不能只修正面待機圖。

**C3．轉身：用程式部件做有厚度的多角度角色**

建議採用 **8 個主要方向＋角度間部件插值**。保留程式繪製，完成後可烘焙圖集。

不再使用整隻角色水平壓縮至 0.3 的方式。

**角色分層**

```text
底座與接地陰影
遠側腳／遠側手／遠側持物
後腦、頭盔後片、披風、背部配件

臉部
近側腳／近側手／近側持物
必要前景裝飾
```

**轉向規則**

- 頭部保持體積，只允許少量輪廓變化。
- 臉部中心隨角度沿頭部橢圓移動；遠眼逐漸變窄、被輪廓遮住。
- 側面加入鼻部／口部小輪廓，背面不畫眼睛。
- 帽沿、頭盔護頰、盾邊、書厚度有側面專屬幾何。
- 肩、手、腳及持物依近遠側錯開，轉過側面時交換前後層。
- 軀幹先轉、頭略提早看向目標，武器稍後跟上；差距保持短，避免像零件散開。
- 步行轉向保留步相與腳底位置，不能在換角度時滑動。
- 裝備左右手歸屬固定；完整旋轉不等於整張鏡像翻面。

| 人形兵 | 共用頭、肩、手腳的角度骨架，各自加帽與武器 |
| 騎兵 | 人、馬、長槍分開轉；馬頭與身體有側面長度 |
| 蘑菇／史萊姆 | 外形保持體積，臉、斑點、冠飾繞體移動 |
| 寶箱怪 | 蓋板、箱體、鉸鏈、牙與舌頭有前後厚度 |
| 幽靈 | 臉跟著轉，尾部與雙手錯動 |
| 娃娃 | 球頭、鈕扣眼、縫線與針方向一致 |
| 沙漏精靈 | 框架、玻璃、翅片分層，側面仍有框厚 |
| 吸塵貓 | 耳、背包、吸管與口部不可一起壓扁 |
| 石魔 | 肩甲、拳、軀幹有側面面積與遮擋 |

先以**劍士、弓箭手、騎兵、寶箱怪、史萊姆、法師**六種驗證方法，再展開其餘兵種。

Godot 的自訂繪製與繪製變換可支援這種部件式方案；無須先改用外部角色工具。[Godot 4.6 文件](https://docs.godotengine.org/en/4.6/tutorials/2d/custom_drawing_in_2d.html)

容量先不設否決門檻，但要量測：

- 各方向圖集佔用、冷啟動、首次進圖鑑及換塗裝時間。
- 圖鑑高解析預覽與戰場快取分開。
- 分頁／按需產生，避免所有兵種、方向、塗裝全部同步常駐。
- 快取與直接繪製必須有同角度比較表，不能兩套畫法越改越不同。

**C4．圖鑑大圖：固定名稱區，角色使用完整動作包絡**

建議卡片分區：

```text
┌──────────────────────────────┐
│ 名稱、定位、費用              │ 固定標題區
├──────────────────────────────┤
│                              │
│     棋子完整展示區            │ 角色與持物都在此區
│                              │
│ 旋轉／動作／播放／逐格         │
├──────────────────────────────┤
│ 數值、技能、克制與被克制       │
└──────────────────────────────┘
```

- 對每兵種計算所有方向、待機與攻擊姿勢的聯集邊界。
- 以聯集邊界選定固定縮放，不在每一幀忽大忽小。
- 長槍、旗、火罐前搖也計入邊界，不能只算身體。
- 預留約 10% 安全邊；需要時加大展示區，不把整隻縮到難辨識。
- 底座位置穩定；標題區與角色區不能互相侵入。
- 「完整棋子」與「近看細節」兩種視圖；近看可平移，完整視圖一鍵復原。
- 攻擊展示預留目標假人與飛行區，不讓箭飛進名稱或說明。
- 法師普攻、召喚，投彈兵投彈、貼身敲擊等，要能分別選擇。
- 小劇場保留真模擬，不能只靠擺姿勢驗收攻擊。

**C5．共同驗收：每種兵都有可逐格核對的證據**

每次檢查包標明版本、兵種 ID、角度、狀態、規則碼與種子，輸出：

1. **360 度影片／GIF**
   - 每兵種 4～6 秒，完整一圈。
   - 正常速度與慢速各一份。
   - 附 16 個角度的靜態拼表，用來檢查側面與遮擋。

2. **持物細節表**
   - 握點、護手、柄尾放大。
   - 前後左右與攻擊關鍵姿勢。
   - 同時提供原尺寸，確認縮小後仍看得懂。

3. **攻擊逐格表**
   - 前搖、離手、飛行中點、命中前、命中、收招。
   - 標出展示 tick、傷害 tick、HP 前後值與音效時點。
   - 不以 GIF 作為唯一精確驗收資料，另附影片與逐格圖。

4. **圖鑑版面表**
   - 四語、三個既有字級。
   - 完整動作包絡與名稱區疊圖。
   - 若新增 175%，獨立增加一組。

5. **真戰鬥案例**
   - 遠程近距離與最遠距離、移動目標、盾兵。
   - 施放者同 tick 死亡、目標死亡、多發同點爆炸。
   - 暫停、倍速、倒回、跳轉、減少特效與色盲模式。

共同確認表：

| 兵種 | 轉身 | 握持／部件 | 攻擊同步 | 圖鑑構圖 | 結論 |
|---|---|---|---|---|---|
| 每種一列 | 通過／問題編號 | 通過／不適用／問題編號 | 通過／問題編號 | 通過／問題編號 | 待修／待複核／通過 |

使用者可以回覆「騎兵 135° 槍桿穿手」，我們能直接重現，不必重新描述整段動畫。

**D．V1.4 基礎上需要完成的大項**

**D1．大廳重整：先選玩法，再看條件，再擺陣｜必做**

承接 V1.4 裁決 B23、B25：

- 頂部只顯示模式、雙方、規則摘要與續局狀態。
- 左側顯示本戰條件，中央棋盤，底部兵種卡，右側選取兵種說明。
- `Beats／Fears` 改成完整本地化的克制／被克制區，不擠在擺陣頂欄。
- 進階七類規則收進抽屜式編輯器，主畫面只顯示與標準不同之處。
- 契約、貼紙、巨獸、宿敵的效果先摘要；選取可展開詳細條件。
- 非法陣型直接標出哪隻兵、哪個條件，提供定位。
- 開戰是唯一主要動作；清空、載入、匯入降低視覺權重。
- 設定頁開關與規則編輯器使用同一套控件行為。

**D2．結果頁重整：讓玩家知道下一步與發生原因｜必做**

承接 V1.4 裁決 B25：

- 第一層：勝負、耗時、剩餘戰力、關卡／契約達成狀態。
- 主要按鈕依模式變成下一站、下一局或再試一次。
- 第二層：重播、時光機、統計。
- 分享卡、GIF、出題、接力收到「分享與工坊」。
- 損失原因使用可查證事件，例如「第 24 秒右路失守」，點擊跳到重播。
- 不把相關性寫成因果；無法證明時顯示事件描述。
- 競猜明示原先選擇、實際勝負、差距與得分公式。
- 車輪戰明示留下哪些殘兵；雙封蠟顯示三封總結果。

**D3．大量混戰：整理地面、棋子、飛行物與事件層級｜必做**

- 地面先畫範圍與機關；角色依腳點排序；空中飛行物按高度及必要遮擋處理。
- 機關預警、時停、衝鋒／破陣等關鍵訊息高於普攻裝飾。
- 飄字在短時間窗合併，治療與傷害分流，重要狀態不合併掉。
- 同類爆炸保留各自實際位置，減少的是煙塵與殘片。
- 選取單位顯示目標、狀態及受遮擋輪廓。
- 事件列可篩選隊伍與事件類型，點擊定位／跳重播。
- 簡化模式保留敵我、傷害來源與危險區域。

這符合 Riot 對特效層級、輪廓與減少雜訊的設計原則；此處是對本作的具體套用。[Riot 原文](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)

**D4．新玩法平衡與流程補完｜該做**

不再只看隨機陣型總勝率。

- 巨獸：近戰斷臂路線、純遠程、混編、廉價大量兵分開驗證。
- 車輪戰：殘兵累積是否滾雪球、支援兵是否過強、最低預算補正是否可利用。
- 輪抽：先後手、卡池組合、AI 選卡與實際可部署性。
- 雙封蠟：先封／後封、平手、交接資訊是否洩漏。
- 遠征：契約永久加成、貼紙、事件獎勵的疊加上限與強勢組合。
- 每週棋盒：題目種子、卡池、對手與規則摘要固定保存。
- 幽靈軍團：保留既有 ID；修改內容另開版本，不能讓已通關 ID 指向另一陣型。
- 測試使用鏡像換邊、固定代表陣、隨機陣與刻意尋找漏洞的陣型。
- 先建立基準，再決定調數值；任何改戰鬥的調整都走版本與規則碼。

**D5．資料、代碼與重播生命週期｜必做**

- 匯入先預覽類型、版本、模式、規則差異與合法性。
- 對損毀、過長、未知欄位、不合法兵種、越界位置提供明確錯誤。
- 舊重播支援時使用對應規則；不支援時明示，不能用新版偷偷重算。
- 分享檔標示遊戲版本、規則版本、數值摘要。
- 設定、規則、進度各自遷移與備份。
- 匯出中切頁、退出、磁碟滿與失敗都能恢復，不留下無限等待。
- 模式切換繼續驗證每日、每週、車輪戰、封蠟與遠征狀態互不污染。
- 舊金標準與對戰指紋列為回歸門檻。

**D6．四語與大字級收尾｜該做**

- 簡中、日文優先校對玩法、勝敗、資料刪除、契約與規則用語。
- 統一兵種名、數量詞、時間單位與技能名。
- 所有新設定說明、動作名稱、規則差異都進翻譯流程。
- 驗證文字換行、焦點捲動、長名稱與數值變動。
- 未校對語言繼續明示狀態；程式版面檢查不能取代語意校對。

**D7．Steam 與 Deck 前置｜該做；外部實測獨立列管**

- Steam 排行榜後台建置、測試資料隔離、上傳／下載與離線補送實測。
- 成績攜帶題目版本、規則摘要與必要驗證資料。
- Cloud 做兩裝置衝突、舊檔、新檔與中斷復原測試。
- 手把全流程、重綁、熱插拔、文字輸入與按鍵圖示。
- Deck 驗證字級、效能、功耗、休眠喚醒、觸控與匯入輸入法。
- Steam 缺席時核心玩法正常運作；排行榜入口顯示實際狀態。
- 不把「程式已接」寫成「後台／實機已驗證」。

Steam 相容性判定依平台審查與實際裝置結果，提案中的測試不能自行視為認證。[Steamworks 文件](https://partner.steamgames.com/doc/steamdeck/compat)

**D8．可新增玩法：戰術試驗桌｜可做**

優先於再增加一個獨立大型模式：

- 任選雙方兵種、數量、位置與既有規則。
- 一鍵鏡像、重置、連跑固定種子組。
- 指定觀察兵種、顯示狀態、慢速與逐格。
- 保存試驗碼，從圖鑑直接進入。
- 使用同一模擬器，不做另一套假戰鬥。
- 自訂試驗與正式紀錄、成就、排行榜分開標示。

用途同時涵蓋玩家學習、角色檢查、平衡重現與問題回報。
