# V1.3.0 第 1 輪底稿（Claude）——「活起來、像手作、一眼看懂」

使用者原話：角色紙片感（可能轉身的時候或是什麼）；整體畫面不要太機器感、電腦感；畫面簡潔清晰好懂；有什麼想加、好玩的想法都可以提，不侷限。

## 硬限制
- 模擬、數值、舊對戰碼／重播／殘局解不能變：FINGERPRINT b8fe741bcbfcf800、數值摘要 288176c5c9af5a79 不動。新玩法只能走新規則碼或純畫面。
- 繪圖 p95 不超過 V1.1（8.90 ms）的 +10%（V1.2.1 已 9.61）；V1.3 想加特效就要先省。Compatibility 渲染、立即模式 _draw、精靈圖快取（每兵 face=+1 烘焙，貼圖時 scale.x=±1 翻面）。
- 簡化特效（reduce_fx）、簡化介面、色盲、手把、兩語三字級版面檢查都要過；零預算美術（程式繪製＋CC0）。

## 紙片感的成因（讀程式）
1. 轉身瞬間鏡像：`battle_units.gd:472` face = sign(u.fx)，一幀從 +1 變 −1，整張貼圖左右翻，最像紙板。
2. 所有同兵種動作同步：呼吸只有 `sin(t*3 + x*0.05)`，同一排的兵看起來像複製貼上。
3. 沒有厚度與接地：一張平貼圖＋底圈，沒有側面暗邊、腳下接觸陰影跟著起伏不明顯。
4. 沒有次級動作：披風、羽毛、武器不會慢半拍跟隨；停步時沒有慣性。
5. 受擊只是閃白圓形＋退 4px；死亡另有動畫（`_draw_death`）但仍偏平。

## A 角色立體與生命感（純畫面）
- A1 轉身：face 改成連續值 −1..+1，0.12～0.18 秒內 scale.x 經過窄位（不到 0），中途身體壓低、加一點小跳與腳下揚塵；窄位時疊側面暗色剪影假裝 3/4 側身。攻擊中不轉。
- A2 錯開：每隻兵用 id 給呼吸相位、速率 ±10%、體型 ±3%、待機小動作（張望、整理武器、換腳）隨機間隔。
- A3 厚度：背光側 1～2px 深色描邊位移（假厚度）、統一光源方向（左上），和地圖調色同一光向；接觸陰影隨起跳縮放、走路時前後擺。
- A4 次級動作：披風／帽羽／馬尾用一階彈簧跟隨身體位移與轉向（烘焙外加一層即時小件，或分兩層貼圖）。
- A5 移動慣性：起步前傾、停步後仰回正、轉彎身體傾斜；走路踩地小塵土（reduce_fx 關）。
- A6 打擊感：受擊閃色改成短暫白邊＋擠壓、方向性傾倒；擊倒時往後倒、彈一下、留下倒地剪影淡出。
- A7 情緒：勝利／潰逃／被包圍時的表情或小泡泡（!、汗滴、怒）。

## B 去機器感（手作桌遊）
- B1 線條不完美：UI 框、底圈、格線加細微抖動與墨線粗細變化；木紋、紙紋加顆粒；禁止純平漸層與正圓。
- B2 有機動態：所有過場用 ease，數值跳動用彈簧；時間上加微小隨機（不同步）。
- B3 統一燈光：整體暖色調、桌面暗角、景深感（遠處兵略小略淡）；夜晚／黃昏是地圖可選外觀。
- B4 桌遊實體感：擺陣時拿起棋子會抬高＋陰影變大、放下有落子聲與小震動；開場兵從盒子灑到桌面、收場收回。
- B5 聲音手作化：落子木頭聲、紙頁翻聲、羽毛筆寫字聲；同一音效多變體＋音高隨機（已有 ±10%）。
- B6 字體：標題用手寫感字體（OFL），內文維持易讀。

## C 簡潔好懂
- C1 戰鬥畫面減量：HUD 只留戰力條與時間，細節移到暫停／長按；傷害數字預設只顯示大傷害。
- C2 一眼看懂戰況：戰力條旁加「優勢方」箭頭；關鍵時刻（大範圍技能、陣線被突破）放慢 0.3 秒＋鏡頭推近（只是畫面播放速度）。
- C3 剪影辨識：20 種兵灰階剪影測試，太像的加招牌外形（大盾、長槍、尖帽）。
- C4 新手：擺陣第一次進來時的三步提示（拖兵、剋制箭頭、開戰）；按鈕文字動詞化。
- C5 色彩語言：隊伍色、剋制紅綠、狀態色各自一套，全遊戲一致；寫進一頁風格規範。

## D 好玩的新想法（可選，新規則碼或純畫面）
- D1 戰後精彩回放：自動找 MVP 與決勝瞬間，結果頁播 5 秒高光（用重播資料，只是畫面）。
- D2 拍照模式／匯出 GIF：暫停後自由移鏡、隱藏 UI、存 PNG（分享用）。
- D3 兵種外觀收藏：達成成就解鎖配色／帽子（純外觀，不影響模擬）。
- D4 戰前預測：開戰前猜勝方與剩餘戰力，猜中給星星（培養讀陣）。
- D5 觀戰台詞：兵開場喊話、潰逃喊救命（文字泡泡，可關）。
- D6 天氣外觀：雨、雪、霧只是畫面（不改地形規則）。
- D7 新模式候選（要新規則碼）：「援軍」半場時補兵一次、「迷霧開局」敵陣到開戰才揭開、「國王」保護指揮官。

## E 驗收
- FINGERPRINT 不變、統一檢查、版面矩陣、匯出；新增「轉身影格條」截圖、同排兵相位差檢查、灰階剪影表。
- 效能：每項新特效要量 p95；超標要配套省（例如烘焙轉身中間影格）。
- 真人：5 人看 30 秒戰鬥影片「哪裡像紙片」前後對比。
