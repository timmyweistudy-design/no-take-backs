## 使用者回報的 bug：騎兵在上下邊緣打轉（Claude 已重現並查出根因）
- **規模**：120 場訓練池對戰中，有騎兵的 102 場，抓到 **57 次**「40 tick 內走了 >3 格但淨位移 <0.8 格」的打轉。

**根因 A（繞翼途經點來回切換）**：
- `battle_sim.gd` 的 `_flank_waypoint`，判斷「已到過途經點」是看**當下距離 < 400**，而不是記住「到過」：
  ```
  if u.wp_for == tg.id:
      if dist(u, wp) > 400*400: return wp   # 回去途經點
      return (-1,-1)                        # 到了，直衝
  ```
- 騎兵到途經點 0.4 格內 → 改直衝弓手 → 離開 0.4 格 → 又判定「沒到」 → 回頭。
- 途經點的 y 被 `clampi(wy, EDGE, H-EDGE)` 夾在地圖邊界（y=200），所以在邊緣來回。
- 實例：tick 70～114，騎兵在 x 9800～10000、y 200～370 反覆，移動向量在 (-120,-5) 與 (70,97) 之間交替，目標一直是同一個弓手。

**根因 B（追擊移動目標時一步一停）**：
- 「要不要移動」看 `d2 > reach²`（騎兵 reach 750），但「走到哪停」是 `reach - 50`。
- 目標在移動時，距離在門檻附近擺盪，騎兵每隔 1 tick 停一次（mv 在 (0,0) 與 (-54,6) 交替），看起來在抖。

**其他可能相關**：
- 邊界夾擠 EDGE=200。
- 碰撞推擠。
- 嘲諷（2 格內盾兵）與偏好（弓手）之間的目標切換。
- 推擠讓衝鋒累積歸零。
