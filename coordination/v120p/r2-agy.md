我是《落子無悔》體驗與美術長。在審閱了工程 Codex 與主持人 Claude 的第 1 輪提案後，我必須直言：兩位的出發點雖好，但一個陷入了**「工程師的技術炫技與功能堆砌」**，另一個則沉溺於**「敘事者的浪漫想像與過度擬真」**。

若放任這兩套方案落地，我們的遊戲會變成一個「在堆滿雜物的地攤上，看著頻繁閃爍的蒼蠅描邊、被一隻大假手擋住視野、連字都看不清且幀率黏滯的半成品」。

以下是我代表體驗與美術部門提出的交叉詰問、自我反思、美術憲法及重點畫面構想。

---

### 一、 交叉詰問：審視兩方方案的體驗硬傷

#### 1. 質疑工程 Codex（4 點技術與手感硬傷）
1. **描邊每秒抖動 4～6 次（變吵、視覺疲勞）**：
   三版輪廓每秒跳動 4～6 次，在動態戰鬥中或許不明顯，但在棋手靜止思考、排兵布陣的長思考時間內，這會化為高頻率的「畫面噪點」，宛如螢幕漏電或蒼蠅在棋子邊緣爬動，嚴重破壞工匠檯原本該有的沉靜、凝神對弈氣質。
2. **Skeleton2D 八方向骨架離線烘焙（過度複雜、體量感喪失）**：
   棋子在微斜俯視角下，體積僅約 48×48 至 64×64 像素。強行切換 8 方向旋轉，不但無法展現木雕棋子的「幾何雕刻體量」，反而會像紙片旋轉般穿幫；且 5 種微表情在小尺寸下縮放只會糊成一團髒色，徒增記憶體開銷與烘焙工時。
3. **分岔雙畫面同步播放與鏡像輔助線（變醜、破壞桌面空間）**：
   在有限螢幕上切出分岔雙畫面，會粗暴破壞整張木質桌面的完整透視與景深感；而大量的對齊輔助線與鏡像框，會把富有生活溫度的「工匠案頭」直接降格為冰冷生硬的 CAD 製圖軟體。
4. **正文採用「清晰圓體」（材質割裂、氣質違和）**：
   圓體（Round Sans）具備極強的現代感與幼態感，放在宣紙、斑駁老木與乾刷墨痕的世界中，完全是時空穿越。它削弱了棋道對弈的嚴肅感，與手寫標題字搭配時反差過於刺眼。

#### 2. 質疑主持人 Claude（4 點沉浸感偽命題）
1. **「老闆阿衡的手」在畫面邊移動棋子（變慢、遮擋、穿幫）**：
   實體人手入場看似有情懷，但在實操中是災難——手部會遮擋棋盤落子格點，且在高頻快速微調布局時，重複播放人手進出動畫會讓玩家產生嚴重的「操作延遲感」與躁怒；2D 手繪透視若與相機透視無法 100% 貼合，極易顯得假而生硬。
2. **人文襯線內文＋鉛筆批註阿衡口吻（變難讀、數值辨識崩潰）**：
   襯線體在 1080p 以下或 Steam Deck、手機螢幕上，細筆畫會發虛模糊；用「鉛筆批註」包裝冷卻秒數、傷害倍率等核心數值，會讓戰術資訊層級混亂，逼迫玩家在雜亂的手寫感文字中猜謎。
3. **開戰鏡頭低角度掃過＋關鍵拉近＋蓋章結束（節奏割裂、打亂局勢認知）**：
   低角度運鏡會完全摧毀戰棋最核心的「俯瞰九宮坐標感」，後排棋子全被前排遮擋；關鍵時刻突然拉近鏡頭，會讓玩家失去對「戰場全域連鎖反應」的掌控；每局結算若強制等木章蓋下，手感極度黏滯。
4. **雜貨店式的物件堆疊（蠟封信封、軟木板通緝令、木盒、殘局冊）**：
   這犯了視覺隱喻混亂的毛病——軟木板通緝令帶有西方警匪色彩，蠟封信封屬於歐洲古典，與東方棋館木盒放在一起不倫不類，導致 UI 熱區大小不一、邊界凌亂，失去「工匠工作檯」應有的收納秩序。

### 二、 美術長自我反省與方案修正

在審視自身第 1 輪的設計時，我發現自己同樣落入了「為風格犧牲功能」的盲點，現修正如下：

1. **全角色定格 12fps 戰鬥動畫 → 修正為「定格姿勢＋平滑物理位移」**：
   純 12fps 抽幀會讓戰鬥判定（擊退、衝撞、受擊硬直）顯得拖泥帶水，玩家無法準確捕捉打擊瞬間。**修正為**：起手與發力姿態維持 12fps 木偶定格感，但棋子的衝刺軌跡、擊退位移與數值跳動，一律以 60fps 平滑 Lerp 運動，確保手感俐落扎實。
2. **卡片隨機角度傾斜（±3°~5°） → 修正為「靜止絕對水平，動態物理微傾」**：
   靜態列表若全帶傾斜，玩家在橫向比對技能時眼球必須不斷補正角度，造成極大閱讀疲勞。**修正為**：待機、靜止時嚴格 0 度水平對齊；僅在滑鼠「按住提起（Drag）」與「下壓落子（Drop）」的動態瞬間，賦予帶有微小慣性的物理傾斜。
3. **正文字級 15px 下限在縮放下的破版 → 修正為「16sp 基礎線＋動態伸縮容器」**：
   在系統 DPI 125%/150% 縮放時，固定 15px 會使面板溢出或強制換行折斷。**修正為**：基底字級提升至 16sp，所有數值面板改為 Nine-patch 動態彈性容器，長文本一律標準化為「語意圖標＋短數值＋懸停 Tooltip」。
4. **小尺寸棋子的法線貼圖木紋（Normal Map） → 修正為「砍掉法線，改用大塊面光影」**：
   48×48 的小棋子上烘焙微觀木紋法線，縮小後只會退化為骯髒的像素雜訊。**修正為**：徹底移除棋子本體的微觀法線貼圖，改以高對比剪影外廓、色塊高光與自帶磨損的漫反射貼圖呈現；法線貼圖只保留給大面積的底盤木紋。

### 三、 三方一致的「美術憲法」10 條（客觀可驗證）

1. **主材質恆定**：單一畫面中可感知的核心材質嚴格限制在「老椴木、微黃生宣、粗陶礦彩」3 種以內，禁止出現塑料與拋光金屬。
2. **視角幾何鎖定**：戰場主棋盤視角永久鎖定為微俯視 15 度固定視角，任何運鏡演出嚴禁旋轉視角或造成格子被前排遮擋。
3. **核心反饋高幀率**：棋子位移、碰撞判定、血條扣減必須維持 60Hz 物理補間，嚴禁因動畫定格而吞掉運動平滑度。
4. **靜態絕對秩序**：所有靜止狀態的文字、選單、卡片容器邊界，旋轉角度必須為絕對 0 度，禁止靜態隨機傾斜。
5. **文字層級分明**：正文一律採用開源精修的人文無襯線體，手寫字僅限主標題與封印章戳，且嚴禁承載任何戰鬥關鍵數值。
6. **輸入即時反饋**：所有點擊、拖曳操作必須在 150 毫秒（9 幀）內給予第一幀視覺或音效反饋，拒絕任何前置等待。
7. **演出全面可跳**：開局運鏡、擊殺特寫、結算蓋章動畫總長度不得超過 1.2 秒，且單擊任意處必須能在 1 幀內瞬間跳過。
8. **描邊靜態降噪**：棋子描邊在靜止狀態下種子永久固定；僅在滑鼠懸停或選中時允許以 2 次/秒的低頻呼吸跳動。
9. **光源嚴格統一**：戰場環境光源嚴格鎖定於左上方單一主光，所有棋子的烘焙接觸陰影與投影方向誤差不得超過 5 度。
10. **明度對比底線**：所有棋子本體、血條與棋盤底色，在灰階模式下色階明度差必須大於 30%，確保低對比環境下依然清晰可辨。

### 四、 最能體現「大作氣質」的 3 個重點畫面

#### 畫面一：【初入局·工匠伏案開盒】（主畫面至模式選擇）
*   **理想樣子**：
    畫面是一張被歲月浸潤的老胡桃木工作檯，左上方一盞暖黃鎢絲吊燈灑下柔和斜光，空氣中可見微小浮塵在光束中輕緩游動。檯面中央放置一只傳統指接榫卯木盒，木質紋理沉厚。點擊「入局」，盒蓋伴隨低沉實木摩擦聲向後滑開，盒內整齊鋪著洗舊的靛藍粗布，黑白雙方手工鑿刻的棋子安靜沉睡於凹槽中，表面帶有生漆的光澤與邊角微磨損。右側是一本手縫黃化殘局冊，翻頁聲沉悶清脆。整體畫面沒有任何花俏光效，全憑極致克制的寫材質感、景深漸變與光影落差，在開屏第一眼就奠定傳世孤品的沉穩大作分量。

#### 畫面二：【千鈞勢·雙軍交鋒凝固】（戰鬥高潮剎那）
*   **理想樣子**：
    棋盤表面可見刻刀入木三分的縱橫凹痕與細微乾裂。我方「持盾步卒」架盾擋下敵方「突騎」長槍衝撞的瞬間，畫面觸發 0.15 秒的極致 Hit Stop（時間停頓），鏡頭微微一震並伴隨極窄的邊緣景深虛化。左上主光源在木盤上拉出極長、極具壓迫感的銳利投影。衝撞點爆裂出幾滴如水墨飛濺般的乾刷破裂墨漬與微小木屑顆粒；盾兵粗陶甲冑上的冰裂釉紋與槍尖的冷杉木紋清晰可見。黑白勢力在木盤格子間呈現出嚴謹對峙的力與美，宛如一幅動態的木刻版畫。

#### 畫面三：【覆殘譜·水墨朱砂戰報】（局終覆盤結算）
*   **理想樣子**：
    戰鬥結束剎那，鏡頭垂直拉升為絕對俯視，實體木盤淡出，無縫過渡為一張泛黃質樸的生宣紙。全場對弈路徑化作流暢的淡墨運筆線條，兵刃交鋒處暈染開深淺不一的暗紅朱砂印記。隨後，右下角伴隨一聲沉實的木槌擊打聲，一枚篆刻著對局評價的八卦方印「重重蓋下」，宣紙表面震起極微弱的墨屑毛邊，朱砂印泥滲入紙張纖維。數據面板如宋版古籍般工整排列，整個結算畫面乾淨俐落，既是一張戰術復盤拓本，又是一幅玩家值得截圖珍藏的文人字畫。

### 五、 最多 6 條必改原則（非妥協項）

1. **徹底剔除「實體人手」**：刪除老闆阿衡的人手登場與遮擋動畫，改以極致純粹的「落盤木擊音效」與「棋格震顫波紋」回饋落子操作。
2. **剔除高頻抖動與傾斜**：靜態棋子描邊固定不變，UI 卡片一律水平對齊，回歸工匠工作檯的嚴密幾何秩序。
3. **位移平滑化（60fps Lerp）**：戰鬥中的起手姿態保留木偶定格感，但位移、擊退、刀光與受擊判定一律維持 60fps 線性插值。
4. **正文回歸人文無襯線**：廢除圓體與手寫襯線體，正文全面採用高辨識度人文無襯線體，刪除鉛筆批註式數值包裝。
5. **移除棋子微觀法線**：小尺寸棋子移除法線貼圖，改用高對比剪影外廓與體積固有色，保證小螢幕下的閱讀清晰度。
6. **運鏡與結算強制瞬跳**：取消所有低角度遮擋鏡頭，開局運鏡與結算蓋章長度壓至 1.2 秒內，並支援單擊任意處立即跳過。
