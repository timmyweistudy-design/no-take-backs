# 第 2 輪 Claude 交叉詰問（主持人查程式與畫面）

## 對 Antigravity（r1-agy.md）
1. **「工坊底座自定義系統」已經有一半**：塗裝室（`59h_paint.png`，`game_playroom.gd` PAINT_ROWS：藍紅底漆、漬洗、乾掃、木座木料、棋盤框）。方案要寫成「塗裝室 2.0」（加刻花、黃銅墊圈、磨損），不是新系統。
2. **「血條改成底座環形凹槽」**：現在的血條只在受傷 3 秒內、跟拍、低血量時才畫（`battle_units.gd:858`）。改到底座：底座已有隊伍圈（藍圓、紅菱，色盲辨識靠它），再塞血量會打架。改法：血量用「底座外緣一圈刻度被磨掉」只在跟拍／近看時出現，平常維持現制。
3. **「全角色定格 12fps」**：戰鬥要看清誰打誰；12fps 會讓 4 倍速時幾乎看不到動作。改：只用在「表演性時刻」（勝利、開場、待機小動作、技能預備），戰鬥移動與攻擊保持現在的圖集影格；「on twos」做成風格開關的實驗。
4. **「卡片隨機傾斜 1°～3°」**：1.1.0 剛把版面做到 24 組 0 違規，R1～R10 查置中與貼齊。隨機傾斜會讓檢查器全部要改。改：傾斜是「裝飾層」（紙卡外框、照片、便條）＋固定角度表（不是隨機），文字與按鈕的判定框保持正交；版面規則加「刻意傾斜」白名單。
5. **「字級絕不低於 15px」**：現在 100% 的中位字級 15、最小「註記」級 12～13，Deck 字形實高 ≥9px 已擋。我同意加大，但要在 125%／150% 驗證塞得下：先把 12px 級的內容逐頁盤點，能刪的刪、要留的改 14。
6. **「法線貼圖木紋」**：角色才 40～60px 高，法線細節看不到，還要多一張圖集。改：木紋只做在棋盤、桌面、面板這些大面積上。
7. **「Lightmap Bake」**：2D 沒有光照圖；等於「預先畫好的光影貼圖」。採：棋盤與桌面的光影畫進材質，角色只加接觸影。

## 對 Codex（r1-codex.md）
1. **UI 轉 Control／Theme 15～25 日**：現在全部 `_draw` 自繪，版面探針（`probe_*`）＋ R1～R10 檢查器是建在自繪上的。轉 Control 等於重寫檢查器；而「像手作」主要靠材質與排版，不靠用哪一套 UI 框架。我主張**不轉**，改成在 `_draw` 上做「元件庫 2.0」（紙卡、木牌、布標、蠟封各一個畫法函式＋探針）。請第 3 輪表態。
2. **Skeleton2D 骨架**：角色是程式向量畫的，沒有原稿圖層；骨架化等於重做 22 種角色。可行的中間路線：維持程式繪製，但把部件（頭、手、武器、帽）變成資料表＋關鍵姿勢表，動畫用曲線而不是公式——效果接近骨架，成本小一個數量級。
3. **新技能**（架盾、接拍、急救契約）：好，但都是規則改動，要升 `RULES_VERSION`、新金標準、重驗三星——方案要寫清楚走「擴充規則」不碰標準規則。
4. **截圖平行化**：Windows 版 Godot 截圖要真的開視窗；平行 2～4 個會不會互相搶 GPU、讓對比取樣不穩？要先量。

## 補漏（三方都沒提）
- **「大作感」的第一印象是商店頁與預告片**：方案要有「關鍵美術（Key Art）／膠囊圖／預告片分鏡」方向。
- **一致的動態語言**：按鈕按下、面板出現、卡片翻面的速度與曲線要統一（動態規格表），不然各頁各做各的又會像拼湊。
- **在地化的手作感**：日文、簡中、英文標題手寫字要風格一致；英文標題可以手刻，中文要找授權字型或請書法家寫 30～50 個標題字。
- **可回退**：每個美術方向要有「簡化介面」對應版（不是關掉就壞）。
