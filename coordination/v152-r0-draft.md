# V1.5.2 方案初稿（Claude，第 0 版，給三方討論）

定位：排版品質版。使用者 2026-11-09 抓到「低級錯誤」：主畫面第二層卡片面板沒置中、大廳模式分頁下的紅色書籤沒有貼頂。要求：列成完整方案、確認整體排版問題、基於 V1.5.0 與 V1.5.1。
鐵則不變：FINGERPRINT b8fe741bcbfcf800、數值摘要 288176c5c9af5a79 不變；不改數值。

## 0. 根本原因（為什麼會漏）
- `tools/layout_check.sh` 只檢查文字溢出、文字重疊、九宮格內距、對比、點擊框大小、按鈕互撞；**不檢查置中、貼齊、對稱、間距一致、留白比例**。
- V1.5 新寫的面板用寫死座標（卡片面板 `game_menus.gd _draw_hub`：`Rect2(430, …, 800, …)`，中心 x＝830，畫面中心 640），測試和版面檢查都不會報。
- 收尾時把「版面 0 違規」當成排版沒問題，沒有逐張用「找錯」的眼光看截圖。

## 2. 系統性修法：對齊規則＋偵測器（避免再犯）
### 2.1 排版規則（寫進 `docs/ui-layout-rules.md`）
- R1 置中：對話框、彈出面板水平置中於畫面（x 中心＝640±1）；側欄、左欄這類刻意偏位的要在程式標記「側欄」。
- R2 標題緞帶置中於面板，緞帶下緣到第一行內容 ≥ 12px。
- R3 依附裝飾（書籤、緞帶尾、徽章、勾選）：依附邊貼齊（差 ≤1px），水平位置置中於宿主（或明確定義的角落）。
- R4 按鈕列：整列相對面板置中、間距相等；主按鈕不靠寬度不等破壞對稱（寬度差異時以群組置中）。
- R5 卡片內：圖示、標題、說明三段垂直置中或一律從同一基準線開始，同一列卡片一致。
- R6 面板高度貼合內容：內容佔可用高度 < 50% 時縮面板（保持置中），或放空狀態說明。
- R7 文字對齊：置中的標題下的短說明也置中（沿用 layout-subtext-alignment）。
- R8 間距階：只用 4／8／12／16／24px。
### 2.2 偵測器（加進 `tools/dev_main.gd` 版面檢查，所有語言、字級都跑）
- 記錄每個 `_panel`／`_tex_box(paper)`／`_h1` 緞帶／書籤的矩形與「角色」（dialog／side／card／ribbon／bookmark…）。
- 檢查：R1 面板中心偏移、R2 緞帶置中與下方間距、R3 書籤貼齊、R4 按鈕列對稱與等距、R5 同列卡片內容起點一致、R6 留白比例、R7 標題與副文對齊。
- 違規和既有檢查一樣算 FAIL；允許清單（刻意偏位）寫在程式旁，不寫在檢查器裡。
- 先跑一次產出「目前違規全表」，作為本版修正清單的依據（不靠肉眼）。
### 2.3 流程
- 收尾檢查清單加「看圖找錯」一步：每個新畫面都要在拼接觸表上畫中線、看對齊。
- 回報時明寫版面檢查涵蓋什麼、不涵蓋什麼。

## 3. 逐畫面修正（依偵測器結果與 §1）
