# 第 7 批（P2 之一）：戰場辨讀（方案 §7 核心三項）

## 做
1. **戰況字降噪**：純數字的傷害跳字不再包羊皮紙泡泡——無底框、奶白字＋深褐粗外框（手寫感的厚邊）；關鍵字跳字（擊倒、致命、剋制…tier ≥2、非純數字）照舊用泡泡＝「只在關鍵時刻出短標」。補血綠字照舊。
2. **非焦點兵血條淡化**：血條照設定決定要不要畫；畫的時候，焦點兵（跟拍／選中、0.8 秒內剛被打）不透明，其他 50%。低血量（≤35%）提示照舊會畫、但同樣依焦點淡化。
3. **焦點兵腳下水墨暈光**：跟拍／選中的那隻、以及最近 0.5 秒內互相交手的最多 3 隻：腳下一圈淡墨暈（地面層，畫在兵之前）＋1.5px 象牙白外緣。不畫在倒下的兵身上；減少特效時不畫暈、只留外緣。
4. **驗收**：固定時鐘美感比基線（逐畫面不能變差，容差照第 3 批）；24 組全量戰鬥畫面 0 違規；`FX_CLASS` 噪音預算登記新的暈光（地面類）。
5. 測試 `test_battle_read_v150`：純數字判斷、焦點判斷（跟拍、剛被打、最多 3 隻）、血條透明度。

## 這批不做（記錄）
- 外圍地面降飽和 20%（要做遮罩保護隊色與地形語意色，需要另一個繪圖通道；排在地形微縮批一起做）。
- 致命一擊頭頂印章短標、交戰區跳字面積 ≤15% 的取樣器（下一批：先把字降噪的效果量出來）。
- 地形微縮、故事物件、決勝暖光。
