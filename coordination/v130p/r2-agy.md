4. **同意八方向圖集採離線分頁烘焙與 LRU 快取，拒絕全量常駐**：
   美術希望賦予 22 種兵豐富的轉向與招牌微表情，若按 Claude 的天馬行空全部塞進常駐記憶體，必然會直接擊穿 160MiB 預算並引發整頁讀回尖峰。分頁快取是保障高精度手繪木紋資產能順利落地的關鍵工程護欄。

##### 【從體驗與美術角度不同意】
1. **不同意因 Compatibility 渲染器限制而輕易妥協「真景深（DoF）」**：
   Codex 因景深需改 Forward+ 而將其列為高風險、建議只模糊盤外甚至割捨。但「微縮模型感（Diorama）」最關鍵的視覺心理暗示就是移軸鏡頭的邊緣景深！若完全沒有邊緣景深，棋盤在傾斜視角下仍會暴露「電腦繪圖平鋪」的破綻。體驗端主張即便不用原生 3D 景深，也必須在 2D 後處理層用固定邊緣漸層模糊遮罩（Vignette Blur Mask）實現假移軸，絕不能向純銳利邊緣妥協。
2. **不同意將「社群題包訂閱、非同步擂台、逐格地形編輯」列入 1.3.0 增量清單**：
   這三項功能極度依賴後端託管與資料庫治理，且需要龐大的 UI 介面去承載表單與清單。1.3.0 的核心命題是「棋館活起來」，工程資源若被大量分散至聯網與編輯器邏輯，必然會大幅壓縮「去模板化介面」與「角色定格動態」的實裝工時，導致外觀精修半途而廢。
3. **不同意因 3D 桌面成本高（35～60日）而傾向退守純 2.5D 平面投影**：
   Codex 評估正交 3D 成本高昂，但純 2.5D（Sprite 壓扁與傾斜矩陣）在面對積木牆體、榫卯倒角與斜向光影時，會產生嚴重的紋理拉伸畸變。淺模型正交 3D 桌面能一次性解決滑鼠反投影與高低差投影問題，長遠來看維護成本反而低於充滿補丁的 2D 偽 3D 矩陣。
4. **不同意僅以「line boil 輪廓低頻切換」替代定格木偶動態**：
   Codex 提出的 line boil 只是手繪線條的低頻抖動（如 Cuphead 的紙張抖動感），這符合漫畫手稿，但完全不符合本作「發條實木微縮偶」的物理世界觀。我們要的是關節與四肢的 12fps 抽幀定格感，而非線條輪廓本身的有機蠕動。

   自動戰棋在戰鬥中盤最容易讓玩家陷入「冷眼旁觀的疲勞感」。適度的運鏡引導能放大兵種 3.0 的招牌姿態與微表情，把數值結算昇華為精彩的定格木偶對決微電影。

1. **不同意預設三段式鏡頭（擺陣俯視 → 開戰降到桌邊 25～35° → 結果拉回）**：
   鏡頭在擺陣與戰鬥之間進行大幅度的傾角翻轉，會造成嚴重的空間認知斷裂；開戰傾斜至 35° 時，後排兵種會被前排大體積單位（如騎兵、盾兵）徹底遮蔽，嚴重阻礙玩家判讀交戰走勢。鏡頭傾角應固定在更平緩的 18°～22°，全程保持溫和透視，切忌劇烈俯仰。

3. **不同意「8 方向先做 3 兵，其餘 19 兵維持水平翻轉」的折衷做法**：
   在微傾角鏡頭下，3 個兵擁有立體的斜向與背面視角，其餘 19 個兵卻靠左右翻轉應付，兩者同屏混戰會產生極為突兀的廉價感與「半成品割裂感」，直接擊碎大作幻覺。寧可全兵種統一先做精緻的「5 方向（正面、正側、背面、斜前、斜後）鏡像對稱資產」，也不要在同一屏內出現次元維度不一致。

   目前核心 22 種兵的木雕法線、八角底座、微表情與音效實錄尚未完全驗收完畢。過早引入機制複雜的新兵種，會讓平衡性與測試工時全面炸裂，必須守住「先把現有 22 兵雕琢至極致」的品質底線。

### 二、對上一輪（r1-agy.md）的自我修正

檢視專案底線後，我上一輪的提案存在過度沉溺於浪漫視覺、忽視工程約束與戰術底線的錯誤，現進行以下 4 點嚴格自我修正：

#### 1. 字級規範與排版修正（嚴守字級表，絕不縮字）
* **原錯誤**：上一輪提出了「大標題木刻楷體、內文微胖宋體」並隨意規定行距 1.45 倍，甚至主張為了營造手帳感而任意調整排版密度。
* **自我修正**：專案底線明定**「字級只用字級表、絕對不能動態縮字」**。所有去模板化介面（手帳、宣紙戰報、工具箱）必須嚴格套用既有的 Typography Tokens（標題、內文、說明、微標籤等固定階層）。在面對英文 150% 或多語系長文本時，必須依賴「容器尺寸自適應、動態摺疊換行或詳情分頁」來容納，嚴禁透過縮小字體或壓縮字元長寬比來遷就插畫構圖。

#### 2. 隊色系統與可讀性修正（建立色盲模式與雙重幾何編碼）
* **原錯誤**：上一輪過度強調「東方茶室古雅慢時光」，大量使用硃砂、黛藍、古銅等低飽和文人色調，忽略了高對比隊色在不同光照下的辨識度。
* **自我修正**：戰場隊色是戰術生存底線。紅藍雙方不得僅憑宣紙水墨色差區分。修正為：
  1. **底座形狀雙重編碼**：我方棋子底座固定為「圓形胡桃木底座」，敵方固定為「八角形紫檀木底座」，即便在完全失去色彩感知的極端情況下也能憑輪廓秒分敵我；
  2. **色盲友善模式**：調色腳本（LUT）與隊色高光必須通過嚴格的紅綠、藍黃無障礙色票對比驗收，保留純色剪影外框選項。

#### 3. 截圖可重現性修正（廢除真實時間動態光影，回歸固定腳本）
* **原錯誤**：上一輪浪漫地提出「老棋館窗櫺隨真實時間（現實生活中的晨昏）灑入晨光、斜陽或雨滴窗影」。
* **自我修正**：這嚴重摧毀了自動化測試與截圖對比的基礎！隨即時鐘變化的光影會導致每次 CI 跑截圖測試時 Hash 碼與像素比對全數報警。修正為：**所有光照角度、色調 LUT 與環境陰影，嚴格綁定地圖與關卡預設**；若要展示晨昏變化，僅能作為獨立的靜態展示關卡，驗收工具與測試環境強制鎖定在固定種子與標準時間光照下，確保 4440 張截圖 100% 逐像素可重現。

#### 4. 資訊不可縮減修正（廢除竹簾盲遮，保留硬核數值透視）
* **原錯誤**：
  * 在 `02_place.png` 革命中提出用「青竹捲簾」把敵陣完全遮死；
  * 在字體數值規範中提出「徹底禁止 HP、DPS、cells/s」，強行改為「射程：六步」、「出招：迅捷」。
* **自我修正**：
  * **敵陣不可遮蔽**：擺陣階段推敲敵軍站位是自動戰棋的樂趣核心。竹簾遮蔽破壞了核心玩法。修正為：竹簾僅作為開場 0.5 秒的拉開動效，或僅在「特殊夜襲迷霧殘局」中出現；常規戰役敵陣完全可見，僅保留底座微暗光表示處於未啟動狀態。
  * **數值雙層查閱**：名詞可以美化（如金幣標為金兩），但硬核戰術數值（精確生命值、DPS、格數）**絕對不能消失**！修正為「雙層資訊結構」——卡面常態顯示雅緻圖章與直觀計量條，但玩家長按、選取或開啟設定時，能立即切換出包含小數點與底層公式的精確數值板，確保硬核配陣玩家的分析需求不受絲毫折損。

### 三、三個最大分歧的體驗與美術立場

#### 1. 鏡頭架構：2D 假透視 vs 3D 正交/低透視
* **我的立場：堅定選擇「淺模型 3D 桌面 + 2D Billboard 立牌（Sprite3D）」**。
* **理由**：
  2D 假透視看似便宜，但本質是「用數學矩陣在 2D 畫布上硬扯皮」。一旦棋盤需要有厚實的榫卯側邊、積木牆體高低差、以及從桌面斜打過來的桌燈投影，2D 假透視就必須寫無數個特例去修補深度排序、遮擋剔除與點擊反投影。
  採用 Godot 的正交/低透視 3D 鏡頭，棋盤與障礙為極低面數的 3D 模型，角色維持手繪 2D 精雕立牌（始終朝向鏡頭或維持固定傾角）。這能以最優雅乾淨的底層架構，天然獲得精準的接觸陰影、積木深度與無畸變的滑鼠格位拾取，既保證手繪木紋的美術靈魂，又徹底終結 2D 幾何補丁噩夢。

#### 2. 角色放大倍率：1.6x vs 1.4x vs 1.25x
* **我的立場：戰場全局基礎尺寸僅放大 1.25 倍（約 30px），但引入「點選/近戰聚焦 1.4 倍」與「結算特寫 1.6 倍」**。
* **理由**：
  戰場是棋盤，不是角色扮演舞台。在檢視 `zh_02.jpg` 密集站位與窄道戰鬥後，若全局放大 1.4～1.6 倍，多個兵種交錯時會形成嚴重的「角色疊羅漢」，玩家根本看不清腳下踩的是草地、冰面還是熔岩，甚至無法準確點選受傷的特定小兵。
  1.25 倍是戰術清晰度與木紋細節的最佳黃金交叉點——它讓臉部表情與手繪木紋比 1.2.0 明顯精緻，又不會侵蝕格子的物理空間。至於玩家想要看清臉部微表情的渴望，應透過交戰局部拉近鏡頭、點選兵種展開實木牌尺、以及結算時的印章特寫來徹底滿足。

#### 3. 定格節奏 vs 流暢判讀：12fps Stop-motion 抽幀 vs 60fps 平滑補間
* **我的立場：「物理位移與血條依循 60fps 原生平滑，肢體動作與表情嚴格鎖定 12～15fps 定格抽幀」的雙軌分離**。
* **理由**：
  若把角色的全局空間位移與血條扣減也強行降到 12fps，在密集混戰中玩家會產生嚴重的「操作延遲感」與「畫面卡頓幻覺」，直接干擾對勝負瞬態的即時判讀；反之，若把木偶的四肢擺動全用 60fps 線性插值補滿，角色就會像抹了潤滑油的塑膠模型在冰上飄，徹底失去手工微縮發條木偶的「咬合力與頓挫感」。
  雙軌架構能完美兼顧兩者：棋子在棋盤上的行進軌跡、碰撞判定與 HUD 血條流暢無比（60fps），但木偶內部的小短腿倒騰、長槍突刺、發條旋轉與豆豆眼眨動，全部以 12fps 定格步進。這就如同《蜘蛛人：新宇宙》或《哈羅德·哈利巴》中的藝術處理，在保證電子競技級判讀響應的同時，將定格工藝的美學價值發揮到極致。

### 四、「最能讓玩家第一眼覺得像大作」的前 5 件事（排序與理由）

大作感（Production Value）並非盲目堆砌 3D 頂點，而是在玩家啟動遊戲的前 30 秒內，透過感官的「物理厚重感」與「精緻自洽感」徹底擊碎廉價小品感。以下依視覺與心理衝擊力進行優先級排序：

#### 1. 第一名：微縮移軸景深與實物光影沙盤（3D 淺模型桌面 + 暖光斜射 + 邊緣移軸柔焦）
* **為什麼排第一**：
  這是打破「手機移植平面遊戲」印象的最強殺手鐧。當玩家第一眼看到的不再是一張貼在黑底上的平鋪棋盤貼圖，而是一張帶著胡桃木榫卯厚度、桌角有微弱茶漬、一盞暖色桌燈在盤面上投下長長立體木牌陰影、且四周帶著宛如單眼相機大光圈移軸模糊的實體沙盤時，真實空間感瞬間立體，微縮世界的儀式感在第一秒就被深深烙印。

#### 2. 第二名：角色 3.0 的手繪木雕法線與 12fps 定格微表情（會呼吸的發條木偶）
* **為什麼排第二**：
  角色是玩家投射情感的核心載體。告別 1.2.0 平扁的 2D 剪影紙片，新兵種擁有木刻凹凸法線、微潤漆面、背後的旋轉發條鑰匙與生動的豆豆眼表情系統（待機好奇、衝鋒瞪眼、撞牆蚊香眼）。動作帶著定格木偶的扎實節奏，倒下時崩散出木屑而非廉價的電腦粒子，瞬間建立起媲美實體精緻收藏玩具的奇蹟感。
