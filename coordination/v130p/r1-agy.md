**——從「電腦化平面棋盤」邁向「老棋館裡的微縮發條奇蹟」**

**提案人**：《落子無悔》體驗與美術長（第 1 輪獨立提案）  
**版本代號**：1.3.0 · Parlor Diorama Edition

## 1. 檢視 185 個畫面：最「電腦感」的 8 個畫面診斷

在仔細盤點 `zh_01～08.jpg`（繁中 100% 接觸表）及 `en_01～04.jpg`（英文 150%）全部畫面後，我們發現雖然 1.2.0 引入了宣紙與木紋，但全遊戲大量核心操作依然殘留著極為沉重的「軟體開發者測試後台」與「試算表工程感」。以下是全遊戲視覺上最生硬、最像電腦軟體的 8 個典型畫面：

### 1. `08_settings.png`（設定主頁）
* **哪裡**：畫面中央主體是呆板的二欄式鍵值對（Key-Value）清單，左側是固定寬度的系統名詞（視窗模式、解析度、垂直同步），右側是一排整齊劃一的「◀ 數值 ▶」箭頭按鈕；底板為死黑的九宮格拉伸深棕框。
* **為什麼**：這是 2000 年代 PC 遊戲設定選單的直接搬移，完全沒有任何生活物件隱喻（既不像翻閱帳本，也不像拉開老抽屜）。純粹是程式變數的陣列列印，電腦感最重。

### 2. `59_profile.png`（個人戰績統計）
* **哪裡**：畫面上半部切出四個乾癟長方形，硬生生塞著「X 40」、「45%」、「0/1」等無修飾數值；下半部則是橫平豎直的成就網格（2/37）與密密麻麻的「出陣勝率百分比表格」。
* **為什麼**：完全是商用 Excel 報表與資料庫後台的直接投影。數字冷硬，毫無層次與收藏質感；完全感受不到是一位常客在老棋館征戰多年的榮譽厚度。

### 3. `53_map_lava_battle.png`（熔岩地圖戰鬥）
* **哪裡**：棋盤中央的地貌區域。熔岩路徑由幾條筆直平滑、高飽和度的純橘色向量矩形色塊構成，底層是平鋪的深灰石塊底色。
* **為什麼**：毫無熔岩地貌的凝固焦黑外殼、無動態熱光折射，更缺乏立體凹陷或高低落差。純粹是地圖編輯器拉出來的「碰撞阻擋區域（NavMesh Obstacle）」，宛如向量軟體平塗色塊。

### 4. `16_review.png`（覆盤：如果當初改一隻兵）
* **哪裡**：右下半部出現一整面藍色折線圖走勢圖、進度條刻度，以及標註著「時間軸分割點 0.1s」、「改換兵種」的機械化條狀控件。
* **為什麼**：視覺風格瞬間跳躍至股票看盤軟體或科學實驗室分析面板（Dashboard）。在原本主打東方木器與西洋玩具的世界觀裡，突兀地插入統計學折線圖與小數點秒數，代入感蕩然無存。

### 5. `05b_result_details.png`（結算詳細數據）
* **哪裡**：中央面板將各兵種表現直接轉化為水平長條統計圖（Bar Chart，如 864、762、514），底部甚至直接印出一串無格式字串「重播驗證碼 920534be6eb...」。
* **為什麼**：標準的網路遊戲 Log 輸出格式。等寬數字、統計長條、開發者除錯用 Hash 碼直接暴呈給玩家，徹底出戲。

### 6. `22_lobby.png`（對 AI 快速對戰大廳）
* **哪裡**：畫面頂部是一字排開的瀏覽器風格 Tab 標籤（標準、經典 5 種、奇幻兵團…）；中央是地圖、大小、對手、規則的四層水平下拉欄，右上角掛著「我的預設 ▼」。
* **為什麼**：完全符合 Windows 軟體「安裝引導精靈（Wizard Dialog）」的排版結構。Tab 按鈕文字偏向上半部（字下方有一條突兀的深色帶），整體僵化冰冷。

### 7. `10_codex.png`（兵種圖鑑 - 騎兵）
* **哪裡**：面板左側整齊列印「HP 350+84」、「DPS 13+05」、「Range 0.8 cells +0.7」、「Move speed 2.4 cells/s +0.1」；右側演示格僅為一塊毫無細節的純平綠草方塊。
* **為什麼**：把遊戲引擎程式碼中的浮點數變數（DPS、cells/s）未經藝術包裝直接貼在木牌上，宛如工程師專用的 Inspector 測試工具。

### 8. `02_place.png`（常規擺陣頁面）
* **哪裡**：棋盤右半部被一整塊巨大的紅棕色純色矩形蒙版遮住，上寫「AI 的陣型 開戰後揭曉」；左下角兵牌右下角「?」偏位、左上角擠著突兀的「5g」方塊標籤。
* **為什麼**：右半部的敵軍遮罩宛如繪圖軟體的「隱藏圖層遮罩」，硬生生切斷木盤空間；棋牌則像是平鋪在螢幕下緣的 UI Dock 欄，缺乏棋子置於棋盒或棋架上的實體收納重量感。

## 2. 美術方向：從「桌面貼圖」到「老茶桌上的微縮定格工坊」

### 是否延續「一張桌上的戰爭」？
**必須堅定延續，但要從「二維平面貼圖」大幅躍遷為「微縮定格景觀劇場（Diorama Theater）」！**  
1.2.0 的宣紙戰報、多寶盒、竹木牌被驗證是本作最具靈魂的資產。痛點不在於「桌上戰爭」這個題材，而在於目前的視角是**正上方 90 度完全無透視的俯視（Top-down Orthographic）**，導致精雕細琢的木材被壓成扁平圖層，角色變成紙片剪影，棋盤周邊淪為死黑空洞。

### 視覺空間核心變革
* **微傾角透視鏡頭（20° Tilt-shift）**：相機從死板 90 度頂視改為微微向前傾斜 18°～22°，賦予棋盤厚實的側邊榫卯木紋與邊緣立體倒角，搭配兩側邊緣極輕微的移軸大光圈景深（DoF），營造精緻玩具沙盤的微縮感。
* **桌面環境實體化**：棋盤不再懸浮於虛空。盤外能看見溫潤的胡桃木老茶桌案，擺放著透著微弱青煙的紫砂香爐、邊緣帶著茶漬的粗陶杯、老花眼鏡與隨意疊放的泛黃對局譜。
* **活著的老棋館**：老掌櫃不再只是一張便條紙。開戰前，老掌櫃骨節分明的手偶爾入鏡替棋鐘上發條，戰局激烈時茶杯飄出微煙，窗櫺隨時間灑入晨光、斜陽或雨滴窗影。

### 三個風格提案

#### 風格 A：【極致物理工藝風】（Hyper-Tactile Woodcraft）
* **特點**：追求極度逼真的材質還原。棋子為亮光烤漆櫸木、黃銅滾邊零件，技能特效完全由棉花球、透明樹脂、彩色玻璃彈珠模擬。
* **參考來源**：實體桌遊《展翅高飛》（Wingspan）配件、《小小大星球》（LittleBigPlanet）。
* **考量**：過於寫實與高光反射容易讓畫面顯得過重、過油，且失去 Q 版角色的純真逗趣。

#### 風格 B（★強烈推薦）：【暖閣繪本工坊風】（Warm Storybook & Living Clockwork）
* **特點**：**溫潤東方插畫筆觸 + 歐洲經典發條木偶 + 充滿呼吸感的棋館空間**。  
  畫面如同在一間藏身於老巷弄深處的古董玩具店。棋子不是冷冰冰的 3D 渲染，而是擁有手繪木紋筆刷、腮紅豆豆眼與活動木榫關節的「活木偶」；動作帶著 12～15fps 的微縮定格動畫韻律（Stop-motion）。棋盤是一塊經年累月盤摸而泛著琥珀光澤的老木盤；戰場特效採用手工撕紙、潑墨微暈與木質碎屑。
* **靈感來源**：
  * *遊戲*：《紙上境遇》（Tearaway）的紙藝生命力、《密林傳奇》（Untamed Tactics）的繪本筆觸、《哈羅德·哈利巴》（Harold Halibut）的停格黏土感。
  * *繪本*：安徒生《堅定的錫兵》經典復古木刻插畫、吉竹伸介充滿哲理的幽默微表情。
  * *工藝*：捷克木偶（Marionette）活動木關節、明清紫檀棋盤榫卯嵌銅工藝。
* **我們如何不一樣**：
  主流自動戰棋（如雲頂之弈）充滿刺眼的霓虹光污染與炫目 3D 粒子，過度電競化；而歐美獨立棋類又常落入陰暗晦澀。《落子無悔》用「東方茶室古雅的慢時光」包裹「熱血純真的木偶微型大戰」，把數值演算轉化為老茶桌上的手作奇蹟。

#### 風格 C：【水墨皮影幻戲風】（Ink & Shadow Box）
* **特點**：將棋盤做成宣紙透光燈箱，角色由多層厚宣紙雕刻上彩，技能演出如皮影翻飛與濃淡飛白。
* **參考來源**：《墨境》、傳統皮影戲。
* **考量**：徹底偏離了「西洋發條玩具兵」的獨特混血魅力，且薄紙在混戰中辨識度大幅下降。

## 3. 角色 3.0：造型、動作、表情與技能演出的具體升級

### 角色系統通則
1. **體積放大 1.6 倍**：戰場單位高寬由原先約 24px 提高至 38～44px，讓木刻手繪筆觸、臉部神采、發條機關清晰可辨。
2. **定格抽幀動態（12fps Stop-motion）**：摒棄軟體平滑線性補間，動作採用微縮定格的節奏跳躍，賦予玩具實體衝擊力。
3. **生動微表情（3-Frame Face System）**：
   * *待機/前進*：發呆豆豆眼、好奇張望或認真抿嘴；
   * *受擊/崩潰*：眼冒金星「> <」、蚊香眼「@ @」或滿頭木刻汗珠；
   * *爆擊/勝利*：挑眉大笑、星星眼「★ ★」或得意吐舌。

### 六種核心兵種 3.0 具體設計

#### 1. 騎兵（Cavalry）——「發條小木馬衝鋒手」
* **外觀造型**：騎在一匹圓滾滾、四足裝著小木輪的紅鬃木馬上，背後插著一枚旋轉發條銅鑰匙；小兵頭戴過大的羽毛金屬高盔，手握一根紅白螺旋紋如棒棒糖的實木長騎槍。
* **動作與姿態**：
  * *衝鋒*：小木馬輪子原地打滑空轉半秒（冒出棉花煙塵），隨後「咻」地彈射彈出！木馬劇烈前後晃盪，小騎兵雙手緊拉韁繩、身子前傾。
  * *撞擊*：長槍平端突刺，伴隨沉悶清脆的「咚——咯嗒！」實木撞擊聲，將敵軍撞飛半格，木馬前蹄高高抬起躍步。
* **表情變化**：衝刺時雙眼瞪大呈圓形驚恐興奮狀；撞中目標時嘴角裂開大笑；若撞上盾兵被截停，整個人往前栽倒、眼珠變成兩團蚊香圈。
* **技能演出【穿陣長驅】**：衝鋒沿途在棋盤格留下兩道微弱的木輪凹痕，撞擊點炸開幾片飛舞的金漆木屑，上方跳出木牌浮雕「破陣！」。

#### 2. 盾兵（Shieldbearer）——「八角厚木樁衛士」
* **外觀造型**：敦厚矮實的八角橡木樁體型，手持一面比自己高出半個頭的黃銅包邊凸面大木盾，盾面手繪著滑稽的大鼻怪獸怒吼圖。
* **動作與姿態**：
  * *移動*：盾牌下露出一雙小短腿碎步小跑，盾牌伴隨步伐左右搖晃。
  * *架盾*：就位時雙手猛力將盾底「磅！」一聲砸入木棋盤接縫，身子完全蜷縮於盾後，頭頂微微露出一撮頭盔呆毛。
* **表情變化**：平時一臉堅定嚴肅的八字眉；成功擋下爆擊時，眉毛挑起露出一顆閃爍金牙；血條過低時，盾牌浮現裂痕，小兵嚇成流淚豆豆眼。
* **技能演出【磐石巨壁】**：承受騎兵衝撞時，盾牌爆發出一圈金色紙箔光暈，伴隨「當——！」的渾厚銅鐘聲，將衝力化作地面微小震顫，小兵頭頂彈出一張迷你紅紙「穩如泰山」。

#### 3. 弓箭手（Archer）——「拉弦彈弓皮帽童兵」
* **外觀造型**：身披墨綠毛氈披風，頭戴一頂小巧獵人帽，背負的小箭筒裡插滿削薄竹籤改裝的吸盤木箭；手中拿著一把帶著天然木結的彎曲柳木弓。
* **動作與姿態**：
  * *射擊*：站定拉弦，身子往後仰成 45 度，弓弦被拉到極限時發出「吱吱」木頭緊繃聲；鬆手瞬間後座力讓他倒退小半步。
  * *箭矢彈道*：箭矢在空中劃出一道柔和的手繪拋物線紅線（紅毛線尾翼），以優雅弧度落入敵陣。
* **表情變化**：拉弦時閉起左眼、舌頭調皮地吐在一側專注瞄準；若被刺客貼身，雙手抱頭跳腳「哇哇」大叫。
* **技能演出【箭雨破空】**：向斜上方連珠發射，天色泛起短暫水墨遮光，五支帶吸盤的箭矢「叭叭叭」釘在目標格子周圍，地面騰起小團手繪灰粉。

#### 4. 投石機/投彈兵（Bomber）——「棘輪木勺拋擲手」
* **外觀造型**：四輪木質小推車底盤，主體是一根粗壯的發條拋石勺；操作員是個戴著厚重防風銅眼鏡的雀斑小木偶，推車後斗堆滿黑陶泥丸。
* **動作與姿態**：
  * *裝填*：小兵手搖側身銅把手，伴隨「哢、哢、哢」三聲棘輪齒輪聲將勺柄鎖死，費力抱起一顆泥丸塞入勺中。
  * *發射*：拉扯引繩，勺柄猛烈回彈「碰！」的一聲將泥球拋出，推車因反作用力向後猛頓。
* **表情變化**：拉繩時緊閉雙目、雙肩縮起害怕炸膛；泥丸精準炸裂時，興奮地甩開雙手原地蹦跳。
* **技能演出【熾火油泥】**：泥丸砸碎在棋格上，爆裂出的不是突兀的電腦紅色光效，而是多層剪紙質感堆疊的暖橘火焰與手繪焦痕，持續燃燒 3 秒並伴隨木炭劈啪的微碎火星。

#### 5. 刺客（Assassin）——「影步披風黑漆飛俠」
* **外觀造型**：啞光黑漆全木身軀，脖子纏繞著一條飄揚的朱紅長絲帶；雙手反持兩把銀漆薄刃木匕首，足底貼著消音軟木墊。
* **動作與姿態**：
  * *潛伏*：開戰瞬間身軀化作一團如墨滴入清水般的灰煙散開，藉由棋盤木紋陰影急速滑移至敵陣後方。
  * *突襲*：在目標身後破土跳起，雙刃高舉由上而下呈「剪刀手」十字交叉切下。
* **表情變化**：平時眼神如兩道銳利刀鋒冷峻無比；背刺成功時眉角揚起狡黠邪笑；若突襲被防護罩彈開，圍巾倒豎成毛刺狀驚恐萬分。
* **技能演出【絕影連刺】**：命中瞬間，畫面出現 0.08 秒極短的黑白水墨定格，敵兵背部撕開一道硃砂裁紙切口，空中炸出一串微縮碎紙花與鮮紅木印爆擊字樣。

#### 6. 狂戰士（Berserker）——「旋風發條胡桃鉗」
* **外觀造型**：蓄著一把濃密橘紅麻繩假鬍子，頭戴雙角鐵木頭盔，胸膛露出一排咬合的咬齒齒輪，雙手各持一柄厚實的月牙大木斧。
* **動作與姿態**：
  * *待機*：雙腳原地焦躁踏步，雙斧互敲發出清脆的「篤、篤」金石聲。
  * *大風車旋轉*：發條全開，整個人化身為高速旋轉的小陀螺，平舉雙斧橫掃周遭九宮格。
* **表情變化**：滿血時怒目圓睜；進入嗜血狂暴狀態時，麻繩鬍子向上翹起，口中露出整排木製大白牙咆哮大笑，頭頂冒出動漫般的白色蒸汽團。
* **技能演出【血怒狂嵐】**：旋轉時帶起周圍木盤上的落葉與木屑旋渦，被劈中的敵兵像陀螺一樣被打得原地打轉 360 度，物理打擊感極其扎實爽快。

## 5. 字體、數字、色彩與置中規範

### 5.1 字體與排版家族
* **大標題與大印章**：**手刻木版楷體 / 康熙字典體改進版**。筆劃帶有天然木刻刀鑿痕跡與輕微吸墨暈染，嚴禁使用平滑的現代無襯線黑體。
* **內文與劇情**：**手寫微胖宋體（如精修仿宋）**。字重均勻、橫豎轉折帶圓角，行距固定為字高的 1.45 倍，確保閱讀呼吸感。
* **數字與量詞（徹底去除電腦縮寫）**：
  * 徹底禁止「DPS」、「HP」、「cells/s」、「5g」等程式碼直出名詞！
  * 金幣改為**微型金元寶圖標 + 手寫小楷數字**（或「五兩」）；
  * 射程改為**「射程：六步」**；攻速改為**「出招：迅捷 / 沉穩」**；
  * 數字採用**略帶襯線的手刻凹雕阿拉伯數字**，字形溫潤古雅。

---

### 5.2 「絕對置中」工程規範（徹底根治 r0-brief 第 10 點）

針對測試工具實測抓出的 **295 處按鈕未置中、184 處方塊文字偏移**，制定以下不可違背的排版法規：

```
                 【幾何中心 vs 光學視覺中心修正】
    ┌───────────────────────────┐  ▲
    │      [ 按鈕幾何外框 ]      │  │
    │  ┌─────────────────────┐  │  │ 扣除底部立體陰影 (如 4px)
    │  │   【光學受光容器】   │  │  ▼ ─────────────────────
    │  │      ┌───────┐      │  │  ▲
    │  │      │  字   │      │  │  │ 文字錨點垂直微調 (-2px)
    │  │      └───────┘      │  │  ▼ (抵消中文字型 Baseline 下墜)
    │  └─────────────────────┘  │
    └───────────────────────────┘
```

1. **光學中心取代幾何包圍框**：
   * 過去按鈕未置中，多因按鈕帶有「底邊凸起立體厚度（如 +4px 底部陰影）」或「縫線邊框」，程式碼直接以 Sprite 外框居中導致字體肉眼偏下。
   * **規則**：文字對齊容器必須是**「排除陰影與邊框後的純光學正面可視區域（Inner Face）」**。
2. **單字元符號「?」與小數字專門鎖定（修正 +6px/+5px 偏心病）**：
   * `02_place.png` 兵牌右下角「?」說明鈕偏移 6 像素問題，源於動態字型 TextLine 帶有字型 Ascent/Descent 預設邊界。
   * **規則**：圓形圖標內的單一符號（如「?」、「!」、數字「5」），全面改用**預先烘焙對齊的純向量路徑（Vector Path）**，直接鎖定於圓形幾何圓心，禁絕使用字型文字框排版。
3. **Tab 標籤頁垂直偏移修復（修正 -15px 頭重腳輕）**：
   * 針對大廳頂部標籤字體偏上的問題，嚴格規範：計算 Tab 文字垂直居中時，必須將 Tab 下緣裝飾色帶視為獨立子節點，**對齊錨點只取上方主要受光面高度**，確保上下內邊距絕對對稱（`Padding_Top == Padding_Bottom`）。
4. **明確區分「格子」與「卡片」法規**：
   * **格子（Cell / Slot）**：一框一詞或單一數值，**必須 100% 幾何與光學雙重置中**（容許誤差 0 像素）。
   * **卡片（Card / Banner）**：一框多行資訊，嚴禁散落，一律採用「標題置中，屬性清單左端固定對齊，圖示右端對齊」的格律化排版。
