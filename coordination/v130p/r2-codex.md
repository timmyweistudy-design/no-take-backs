**3．R11 最終定義**

採「設計目標零偏差，驗收每軸 ≤1 邏輯 px」。0 像素不適合直接約束縮放、字型柵格化與奇偶寬度；1px 是誤差預算，不能當固定下移量。

格子按語意登記；卡片內的價錢子格仍須測。令 F 為明確宣告的正面內容區，排除厚底、陰影及色帶；G 為整段實際字形聯集，含換行與後備字型、不含描邊陰影；O 為登記光學偏移：

`e＝center(G)－center(F)－O`

反算至元件邏輯座標後，`max(|ex|,|ey|)≤1`，且不得越界。報告同列原始偏差、O、殘差；不要求外框幾何中心與光學中心同時重合。

登記表格式：  
`元件ID｜字串/符號｜語言｜字型雜湊/字級｜狀態｜F定義｜O(dx,dy)｜理由｜校準截圖｜審核者`

O 預設零；禁止全域 −2px 或逐張截圖調值。缺登記、超差、越界均失敗；24 組全驗，換字型即重校。

**4．建議依賴順序**

先鎖規則相容、語意色、字級及可控時鐘 → 建立 R11／截圖清冊 → 三兵一圖比較鏡頭 → 鎖投影、點擊反算與驗收座標 → 地形高度及遮擋 → 角色尺寸與三兵八方向 → 圖集、光影、Deck 效能 → 全兵種與介面構圖 → 事件驅動聲音、敘事、導播 → 全量驗收後拍商店素材。
