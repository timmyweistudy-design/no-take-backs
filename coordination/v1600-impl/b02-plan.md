# B02 紙面鈕看得清（P2.2）

方案 §4 B02：版面檢查器加「細描邊白字偵測」，修 `v16_01` 導覽頁等違規；驗收＝24 組 0 違規、新偵測抓得到 1.5.0 異變實驗室舊版。

## 做法
- 偵測：`_btn` 在探針模式把「實際畫成淺紙面」的按鈕範圍登記到 `probe_paper`（`last_btn_paper` 同一個判斷）；`dev_main._contrast_issues` 對亮字（相對亮度 > 0.45、非停用、非輸入欄）若字形中心落在紙面範圍內＝「淺紙白字」違規。紙面上又蓋深色底的（敵方名牌胡桃木、「新」朱漆小牌）登記 `probe_unpaper` 排除。
  - 第一版用取樣背景判紙面：360 筆誤報（取樣器取最壞點，會把字旁亮邊當背景），改成畫的時候登記。
- 修正（全部改成 `_ink_mode = last_btn_paper` 或 `_ink(...)`）：標題卷軸非主牌名稱與副標、新玩法導覽列、覆盤換兵價錢、接力殘局價錢、一陣三考三張卡。
- 測試 `test_paper_ink_v1600`（ui 組）。
