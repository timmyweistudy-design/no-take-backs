# B05 第一幕（S9；P8.1、P8.2）計畫

方案 §5 B05：S9 判決＝首開便條 ≤35% 屏、冷啟到開戰 ≤3 次點擊、IN-160-02（首開便條、卡片面板主牌與抽屜：停用、返回、手把）。回退：只選語言＋一鍵進館。

## 起點（1.6.0 B06 後）
- 首開是置中對話框（語言、字級、一鍵調整、開始），約 810×500＝螢幕 40%，背後整頁壓暗 92%（示範戰場看不到）。按「開始」→ 掌燈開門 → 標題。
- 標題左欄五塊木牌（對戰、連勝遠征、殘局、遊戲間、收藏）；冷啟到開戰：開始 → 對戰 → 對 AI → 大廳三步＝6 次。

## 做法
1. P8.1 首開入館便條：改成桌上一張便條（左側桌緣、≤35% 屏、不壓右邊示範戰場；背景只輕壓暗），內容：語言、字級、一鍵調整（收成一列小鈕）、兩顆鈕「進館」（＝原本開始）與主鈕「開第一局」（設定完直接進對 AI 大廳的確認步，用預設規則）。
2. 冷啟 ≤3：開第一局 → 大廳確認步（第一次也直接在第三步）→ 開戰；選語言不算必要點擊（預設依系統語言）。
3. P8.2 卡片面板：五塊改桌上三主牌（對戰、連勝遠征、殘局）＋「更多」抽屜（遊戲間、收藏；抽屜打開是同款小木牌清單），試玩版停用照舊。手把：主牌、更多、抽屜項目都走得到，返回關抽屜。
4. 狀態小字（新手先教學、遠征第 N 站、每日未打）照舊掛在對應牌上（每日未打在抽屜鈕上）。

## 驗收
- 量測：首開便條面積比（版面輸出記 first_run 面板框）≤35%、不和示範戰場框相交；冷啟點擊數（截圖流程真畫面走一次：首開 → 開第一局 → 開戰，印 FIRSTRUN 點擊數）。
- 測試 `test_first_act_v1600`（IN-160-02：停用、返回、手把、同幀第二輸入）；24 組 0；固定時鐘不比基線差。
