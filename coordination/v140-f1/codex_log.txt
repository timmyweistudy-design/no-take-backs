- 舊對戰碼、重播、殘局解不能變（`FINGERPRINT b8fe741bcbfcf800`、數值摘要 `288176c5c9af5a79`）。會改戰鬥的玩法一律走新規則欄位，缺欄位走舊路。

## 2. 各項細節

### #1 戰術時光機／一子之差
- **現況**：輸了以後的「覆盤」已經可以改一隻兵、重算、比較兩條走勢、播放「如果」。
- **新增**
  - 重播暫停時出現「時光機：回到開戰前改一隻兵」，直接進覆盤。
  - 覆盤算出兩條時間線第一次不一樣的那一秒，在兩張走勢圖上畫分岔記號，並寫出「第 N 秒開始分岔」。
  - 播放「如果」時從分岔前 2 秒開始；原本那條時間線同步在跑，兵的位置畫成地上的白圈（隊伍色小點）。看得出哪裡開始不一樣。
- **規則碼**：不動（覆盤本來就只看不算）。
- **驗收**：分岔計算與時間線同步的測試；覆盤截圖兩語三字級。

### #3 戰利品契約
- 遠征每戰前多一個選項「簽契約」，從 3 份抽出的契約選 0～1 份。
  - 例如：不准帶遠程、只能帶 N 種兵、要在 45 秒內打完、我方少 10 金。
  - 達成就拿額外報酬：多一次事件三選一，或下一戰多 10 金。
- 判定只看戰前配置與戰後狀態，不改模擬（和殘局目標同一套判定）。
- 介面：在遠征的戰前節點下方放一張羊皮紙契約卡，打勾簽名；結果頁顯示「契約達成／失敗」。

### #2 宿敵戰記
- 遠征裡打敗你的那個敵陣會被記成「宿敵」：取一個稱號（例如「雙橋的長槍牆」），存它的陣型、規則與你輸的次數。
- 之後的遠征有機率在菁英節點遇到它：它會強化（+10 金、AI 高一級），開戰前有一張宿敵卡。
- 打贏就是「復仇」，寫進戰績頁的戰記。
- 不改模擬：宿敵就是存下來的敵陣＋既有的遠征加成參數。

### #4 軍令連鎖
- 新的殘局章「軍令」10 關：關卡給定手動技能、次數與冷卻，玩家在時間軸上排 3 道施放時間，解連鎖。
- 時間軸介面要做成可拖曳的木刻度尺。
- 沿用既有的手動技能與定時施放紀錄（第 9 章已有腳本），規則碼已存在。

### #5 接力殘局
- 殘局工坊碼加一條修改鏈。破了朋友的題之後，可以「只改兩隻兵」做成新題傳回去。
- 碼裡帶上一手的作者解與修改次數。
- 新前綴 `NTP2.`，舊 `NTP1.` 照舊能用。

### #6 最小成本懸賞
- 每一關記下你的最佳「花費／兵數／時間」三項。
- 結果頁畫一張本地分佈圖：曲線是隨機擺法基準，上面標你的位置。
- 全球榜要接 #7，列為後續。

### #14 戰報明信片／GIF
- 結果頁「做成明信片」：把翻盤瞬間的截圖、雙方陣型縮圖、勝負、重播碼排成一張羊皮紙卡，存成 PNG。
- GIF 用程式自己編碼：最多 3 秒、低幀數、調色盤量化，放進使用者資料夾。

### #16 觀戰競猜／輪抽
- **競猜**：系統用 AI 生成兩軍，看完陣型押誰贏、押剩多少，答對累積「眼力」分數。
- **輪抽**：雙方輪流從 8 張的公池各抽一張，擺陣開打（對 AI 或雙人）。

### #8 指揮官
- 開戰前選一位將軍（6 位），每位一個全軍被動，加一次性主動（沿用手動技能槽）。
- 例如：「鐵壁伯爵：前排盾兵受傷 −15%」「疾風將軍：開場 5 秒全軍移速 +20%」。
- 要新規則欄位 `cmdr`，有選才走新碼，徽章「娛樂」。

### #9 木座貼紙
- 遠征獎勵與自訂規則可以給單隻兵貼一張貼紙（12 種），例如：開局衝鋒、倒下自爆、第一次受擊無效、攻擊附減速。
- 要新規則欄位，並記在陣型資料裡；新的軍隊碼前綴。

### #11 多波車輪戰
- 新模式：擺一次陣，迎接 3 波敵軍，殘兵不回血（可選一次整備：補 2 隻）。
- 要新規則欄位 `waves`；每波是一般對戰，殘兵帶到下一波。

### #10 沙盤機關
- 地圖可帶「定時機關」：第 N 秒某幾格崩塌成擋路、火牆燒 3 秒、推撞板把格上的兵推 1 格。
- 開戰前畫在地圖上，附倒數。
- 要新規則欄位與動態尋路，只在新地圖變體出現。

### #13 雙封蠟戰書
- 雙人模式變體：雙方各擺 3 個陣，封蠟後依序兩兩揭曉交鋒，三戰兩勝。
- 本機輪流用暗擺，延用既有雙人暗擺流程。

### #12 多格巨型頭目
- 遠征終點的頭目：佔 2×2 的巨獸，有前臂與背甲兩個部位（各自血量，打掉會失去對應能力），會橫掃。
- 要新的單位型別與碰撞半徑（以大半徑近似多格，避免重寫網格），只在新規則下出現。

### #15 塗裝與收藏
- **塗裝室**：每支軍隊選底漆色、漬洗深淺、乾掃亮度、木座材質（4 種）、桌布（4 種），用烘焙時的調色參數實作。
- 只影響外觀，有保存。
- 解鎖靠成就與挑戰。

### #17 簡中、日文
- 依 `docs/localization.md`：
  - 加兩欄字串，翻譯先由 AI 產生、標「未校對」。
  - 字型用 Resource Han Rounded CN 與源泉圓體 JP（OFL）子集。
  - 日文加行首禁則。
  - 版面矩陣加兩語。
- 母語校對交給使用者。

### #18 Steam Deck／觸控
- 觸控：點選＝左鍵、長按＝右鍵、雙指縮放戰場。
- 字級在 1280×800 最小 12px。
- 手把流程走過全部新畫面。
- 實機驗收交給使用者。

### #7 幽靈軍團＋每週棋盒
- **幽靈**：玩家把自己的陣（軍隊碼）上傳到 Steam 排行榜附檔，打的時候從排行榜抓別人的陣。
- **沒有 Steam 時的本地版**：內建 30 個「名人幽靈陣」，由 AI 產生並凍結。
- **每週棋盒**：每週固定卡池與預算，本地紀錄最佳成績；接上 Steam 後同一題可以比排行榜。
- 後台設定與實測交給使用者，不跑 `--steam-test`。

# V1.4.0 裁決紀錄
- 方案 docs/history/2026-11-08-v1.4.0-plan.md；方向候選 docs/history/2026-11-08-v1.4.0-directions.md（v140-r1、r2）。使用者：每一項都完整規劃、全做。
## 第一批（#1 時光機、#3 契約、#2 宿敵；審查 coordination/v140-i1）
- Codex 必修全修：契約存檔欄位與上限、代價不可繞過（修剪超額陣型）、每戰結束結算契約（含輸與第 7 站）、覆盤淡圈回原局要清、分岔 tick +1、和局不算被打敗、宿敵再贏加在原紀錄、宿敵增援守兵種上限。
- Antigravity 美化全採用：米白粉筆虛線圈、分岔線貫穿兩圖、覆盤兩顆按鈕同列、拿掉格子座標、契約羊皮紙籤＋火漆章、「不簽」次要樣式、宿敵木牌、雪恥印章、時光機羊皮紙按鈕。
- Ruling B1：宿敵只在遠征（格子模式）— 遠征是格子陣型，存 (兵種, 欄, 列) 就能重現；自由陣型與地圖變體不收 — 代價：其他模式輸了不會記宿敵。
- Ruling B2：契約獎勵是「永久」加成（和事件一樣）— 契約有代價與風險，報酬要夠吸引 — 代價：遠征後段可能比以前強；存檔上限放寬到 220 金／40 隻。
- Ruling B3：時光機的原本時間線用第二份模擬同步跑（每 tick 多一次 step），不預錄位置 — 確定性保證同 tick 同狀態；成本只在覆盤播放時 — 代價：跳回很前面時要重追。

## 第二批（#5 接力、#6 最小成本、#14 戰報卡／GIF、#16 遊戲間、#8 指揮官；審查 coordination/v140-i2）
- Codex 必修全修：輪抽 AI 用自己的卡池、競猜結果行在報告重建後才寫、離開就取消押注、指揮官預算改成「基礎＋自己加成」（明確記選誰）、GIF 執行緒退出時等寫完、重播碼不印在卡上改按鈕複製；建議也修：錄影中開別的畫面就取消、存圖檢查回傳值與檔名加毫秒。
- Antigravity 美化採用：接力編輯看得到自己的藍軍、戰報卡加深遮罩＋暗金內框＋粗紅印章＋右側大字＋雙方金／兵數、競猜木條標題＋VS＋隊伍色押注鈕、輪抽抽走的卡加隊伍色邊框與火漆印、標題兩顆鈕寬度平衡、指揮官名牌兩列三欄。
- Ruling B4：#6 全球分佈圖不做假資料，本地版只比「本次 vs 自己最佳」；全球榜等 #7 接 Steam — 代價：沒有 Opus Magnum 式的大家分佈圖。
- Ruling B5：#8 指揮官＝手動技能的具名套組＋讓子金，不做全軍被動（被動要新模擬欄位與規則碼）— 代價：將軍之間的差別只有軍令與開局金。
- Ruling B6：#16 競猜的兩軍用 AI 隨機組（每次不同），眼力分只記本地 — 代價：無排行。

## 週數：從 1970-01-05（週一）起算，每週一換題。
static func week_no(unix: int) -> int:
	return int(floor((unix / 86400.0 - 4.0) / 7.0))

## 這週的題目：卡池（舊 10 種裡抽 6 種，一定有戰鬥兵）、預算、對手幽靈。同一週大家一樣。
static func weekly_spec(wk: int) -> Dictionary:
	var r := RandomNumberGenerator.new()
	r.seed = 1400000 + wk
	var mask := 0
	for _try in 50:
		var types := range(D.COUNT)
		mask = 0
		for k in 6:
			var j := r.randi_range(0, types.size() - 1)
			mask |= 1 << int(types[j])
			types.remove_at(j)
		if RuleSet.has_combat(mask):
			break
	var gs := ghosts()
	return {"wk": wk, "pool": mask, "budget": [80, 90, 100, 110, 120][posmod(wk, 5)], "ghost": posmod(wk * 7, maxi(1, gs.size()))}

func _ghost_start(i: int) -> void:
	var gs := ghosts()
	if i < 0 or i >= gs.size():
		return
	var r = RuleSet.standard()
	r.rounds = 1
	rules = r
	challenge_army = ghost_army(gs[i])
	overlay = ""
	set("daily_spec", {})   # Codex v140-i5：不能沿用每日挑戰的狀態
	_start_mode(Mode.VS_AI)
	set("daily_spec", {})
	challenge_army = ghost_army(gs[i])
	ghost_id = str(gs[i]["id"])
	_toast(L.t("gh_toast", [L.field(gs[i], "")]))

var wk_spec := {}   # 開題當下的題目（跨週一才打完也算開題那一週，Codex、Antigravity v140-i5）

func _weekly_start() -> void:
	var sp := weekly_spec(week_no(int(Time.get_unix_time_from_system())))
	wk_spec = sp
	var gs := ghosts()
	if gs.is_empty():
		return
	var r = RuleSet.standard()
	r.rounds = 1
	r.pool = [int(sp["pool"]), RuleSet.all_pool()]

	overlay = ""
	set("daily_spec", {})
	_start_mode(Mode.VS_AI)
	set("daily_spec", {})
	challenge_army = ghost_army(gs[int(sp["ghost"])])
	wk_active = true
	_toast(L.t("wk_toast", [int(sp["budget"])]))

func _ghost_settle(w: int) -> void:
	if mode != Mode.VS_AI or play_kind != "official":

		var beat: Array = Save.data.get("ghost_beat", [])

static func wave_has_lock(units: Array, lock: Array) -> bool:
	for u in lock:
		var hit := false

			if v.has("col") and int(v["col"]) == int(u["col"]) and int(v["row"]) == int(u["row"]) and int(v["type"]) == int(u["type"]):

func _gauntlet_diff() -> int:
	if gauntlet_prev.is_empty():
		return 0
	var a := {}
	for u in gauntlet_prev:
		a["%d,%d,%d" % [u["type"], u["col"], u["row"]]] = true
	var d := 0
	for u in armies[0].units:

			d += 1
	return d

func _puzzle_record(pid: String, spent: int, units: int, ticks: int) -> void:

func _brief_stats(t: int) -> Array:

## 剋誰、怕誰（支援兵左邊改成協同）。試玩版不露正式版的兵。
func _brief_matchups(t: int) -> Dictionary:
	var mask: int = RS.mask(true) if _demo() else RuleSet.full_pool()
	var good: Array = []
	var bad: Array = []
	for o in D.total():
		if not RuleSet.has(mask, o) or o == t:
			continue
		var sc: int = AIT.counter_score(t, o)
		if sc > 0:
			good.append(o)
		elif sc < 0:
			bad.append(o)
	if D.is_support(t):
		good = AIT.SYNERGY.get(t, []).filter(func(o): return RuleSet.has(mask, o))
	return {"good": good, "bad": bad}

本輪依程式與文案做靜態審查，未重跑截圖與實機流程；以下不重列各批已修項目。

整個版本的負擔集中在「不知道現在該做什麼」：遊戲間已有六種玩法，卻分成四張大卡與兩顆小鈕；戰績頁同時承擔數據、成就、宿敵與收藏入口；遠征則把事件、契約、累積加成及下一站資訊放在同一頁，操作順序尤其容易誤解。

視覺上的風險是裝飾沒有固定含義：火漆同時代表選中、封存與完成，手繪圈同時用於位置、分岔與印章；最突兀的資訊則是幽靈頁「對隨機軍勝率」與棋盒的內部週數，容易讓沙盤變成測試報表。

跨功能風險應分兩類：契約、貼紙可持續累積並帶進宿敵或巨獸戰，但宿敵與巨獸不會同站出現；車輪戰入口會重建標準規則，因此「車輪戰＋指揮官」目前應驗證互斥與提示，不應當成支援組合。

**收尾前必修**

- [game_modes.gd](/mnt/c/Users/timmy/projects/no-take-backs/game/scripts/ui/screens/game_modes.gd:714) 的遠征獎勵頁應先選事件與契約，再用唯一的「前往下一站」確認，避免玩家點上方獎勵便跳過下方契約。
- 遠征擺陣頁應提供可展開的「本戰條件」，保留已簽契約、累積加成與特殊敵人說明，避免離開獎勵頁或讀檔後只能靠記憶。
- 貼紙與巨獸應有可重新查看的說明入口，讓滑鼠、手把與觸控都能查到貼紙效果及「近戰才能傷前臂」，不能只靠小圖案與一次性提示。
- [game_result.gd](/mnt/c/Users/timmy/projects/no-take-backs/game/scripts/ui/screens/game_result.gd:310) 應統一結果頁動作層級，保留繼續或重試為主動作、將分享與出題收進固定次入口，並移除車輪戰重複加入的「重播」。
- [strings.csv](/mnt/c/Users/timmy/projects/no-take-backs/game/data/strings.csv:894) 的「永久加成」應改為「本趟遠征持續有效」，並明確區分有戰鬥效果的「木座貼紙」與純外觀「塗裝」。
- 幽靈頁應將「對隨機軍勝率」移入詳細資料，每週棋盒應以日期範圍取代內部週數，並在頁面上寫清楚「打贏後比較花費」。
- 每週棋盒的 `wk_note` 應依實際連線功能顯示狀態，尚未建榜與實測時不能直接承諾「接上 Steam 後可以比排行榜」。
- [layout_check.sh](/mnt/c/Users/timmy/projects/no-take-backs/game/tools/layout_check.sh:29) 應補日文與簡中 150% 搭配簡化介面、色盲及手把的組合，並加入契約結果長文、宿敵長名與每週新紀錄等複合狀態。
- `game/tests/suites/modes.gd` 應補「貼紙獎勵＋縮減預算契約＋續局」的整段驗證，確認自動修剪不會無提示地吃掉剛領的貼紙，且重開後條件一致。
- 模式切換驗收應走「指揮官對戰→車輪戰→幽靈→每週棋盒→一般對戰」，逐站確認規則、敵陣、計分及返回入口，尤其確認未支援的指揮官效果不會殘留。

**之後再做**

- 遊戲間 `_draw_playroom()` 可改成六個同層級入口，補上「單人／雙人」與一句玩法差異，避免底部兩種玩法像附屬工具。
- 戰績頁 `_draw_profile()` 可拆成「戰績、戰記、收藏」分頁，讓塗裝室與宿敵戰記不必藏在數據頁底部。
- `ui_base.gd` 與新畫面可整理共用視覺規則，固定羊皮紙承載內容、木牌承載入口、火漆表示封存或完成，讓選中與手把焦點另有一致標記。
- `strings.csv` 的日文母語校對應優先檢查被縮短的按鈕與規則條件，確認為了塞入版面而刪字後仍能準確理解。
- 發布文件應將本地完成、Steam 尚待接通、全球分佈尚未實作及 Deck 尚待實機驗收分別列明，避免「18 項完成」掩蓋實際可用範圍。
