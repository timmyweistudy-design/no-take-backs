## 2. 底線（不能破）
- 舊場次位元組與 digest 不變（FINGERPRINT b8fe741bcbfcf800）；模擬整數、左右鏡像；畫面狀態不進模擬；改數值要升 `RULES_VERSION`。

## 3. 這次的討論方式（主持人提議，請改）

和 1.5.0（分視角發想 → 交叉評分 → 事前驗屍 → 起草 → 簽核）不同，這次試「**從玩家的一小時倒推**」：

- **R1 一小時日記（三方各自、互不看）**：各選 2 種玩家（新手第一次開、玩過 20 小時的人、只玩雙人的朋友、Steam 商店頁路過的人…），對著截圖寫他們「這一小時」逐分鐘看到、想到、卡住、想關掉的時刻；每個卡點附截圖編號。最後各自列 ≥10 個大方向（每方向 ≥3 細項，每細項有具體做法與一個驗收數字）。
- **R2 一百點下注＋淘汰**：每方拿到另兩方的 R1，用 100 點下注在所有方向上（單一方向 ≤25 點），並且**必須淘汰 3 個**（寫理由）、**必須合併 2 組**（寫合併後的樣子）。
- **R3 切片規格**：得分前 8 名各寫一個「兩天能做完的切片」：做什麼、截圖或錄影怎麼看、Go／No-Go 數字、No-Go 時的退路。
- **R4 主持人起草全案 → 兩方審**：Codex 審可行性、測試、驗收數字；Hydrogen 對截圖審視覺。
- **R5 簽核**：只列必改與結論。

## 4. 每輪交付格式
- 繁體中文；每條附檔案／截圖位置；不寫空話（「提升質感」不算，要寫「哪個畫面、做什麼、怎麼量」）。
- 字數上限：R1 3000 字、R2 1500、R3 2000、R4 1500、R5 600。
- 最後一行：R1～R3「我最想做的 3 件事」；R4、R5「結論：可／有條件／不可」。
