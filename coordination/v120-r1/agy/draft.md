# 落子無悔 V1.2.0 方案：從「能玩」到「像正式出品」（未實作）

> 2026-11-07。使用者需求：現在玩起來還行，但不像公司正式出品那麼精緻，「電腦感」太重。這份方案先找出電腦感從哪裡來，再列出怎麼改，參考同類作品，最後排優先序。只動畫面、聲音與包裝，**不碰模擬**（FINGERPRINT 不變）。

## 0. 診斷：「電腦感」從哪裡來（盤點現況）

| 來源 | 現況（實查） | 玩家感受 |
|---|---|---|
| 聲音 | 戰鬥音效、環境音、**全部音樂**都是 `tools/gen/gen_audio.py` 程式合成，22050Hz 單聲道；戰鬥音樂約 14 秒短循環，分成 4 軌疊加。只有介面音是 Kenney CC0 | 聲音「薄」、像電子琴，聽久了重複；這是電腦感最大的來源，而且玩家感受最快 |
| 角色 | 22 種兵全部是程式向量圖形：正圓、等粗外框（同一個 `OUT` 色）、平塗、沒有明暗、沒有材質 | 乾淨但「太完美」，像向量圖示，不像手繪角色 |
| 場地 | 只有青草平原用了外部素材（Cainos 草地＋9 種植物）；其他 5 張地圖是程式畫的色塊與形狀 | 地圖之間質感落差大；雪原、熔岩像示意圖 |
| 介面 | 全部是程式即時繪製的方框（木紋色塊＋細邊）；圖示也是程式畫的（`icons.gd`）；沒有九宮格貼圖、沒有裝飾 | 像工具軟體或網頁表單，缺少「遊戲 UI」的手工感 |
| 動態 | 換畫面是 `overlay = 名稱` 瞬間切換，沒有過場；按鈕只有變色和按下縮 2.5%；數字直接跳出 | 冷、硬，缺少「彈性」 |
| 特效 | 程式畫的圓、線、多邊形；沒有粒子系統、沒有後製（暈影、泛光、調色） | 打擊感有，但畫面「平」 |
| 包裝 | 標題是文字＋背景模擬戰；沒有標誌圖、主視覺插畫、開場、讀取畫面；Steam 膠囊圖是程式產生的 | 第一印象就像原型 |

結論：**聲音、角色質感、介面材質、轉場動態**是四個主因；特效與包裝是加分項。

## 1. 參考作品：要學的是什麼

| 作品 | 學什麼 | 本作怎麼用 |
|---|---|---|
| Balatro | 東西「從不完全靜止」：卡片懸浮、朝游標傾斜、翻面彈簧回彈＋小幅隨機旋轉；計分是一段有節奏的演出；整體一層 CRT／色彩處理統一質感 | 選卡池卡片、結果頁數字、戰力條都加彈簧與懸浮；結果頁計分逐條「數上去」 |
| Super Auto Pets | 角色是貼紙感的手繪動物、色彩飽和；商店與戰鬥的回饋都很短很清楚；開發者說要「做出自己的樣子」，重畫了太像原型的美術 | 兵的貼紙感外框與陰影；確立本作自己的美術規範 |
| Kingdom Rush | 小尺寸角色剪影清楚、手繪上色有明暗；技能特效醒目但不糊 | 角色加明暗與高光、加粗外輪廓、內線細 |
| Bad North | 柔和粉彩、極簡但統一的色票；「像在玩一盒小玩具」 | 每張地圖一組色票＋調色，讓兵與地圖同一個世界 |
| Into the Breach | 資訊清楚的介面、意圖預告 | 已有剋制提示；介面材質升級時保持清楚優先 |
| TABS | 好笑的音效與角色聲音讓「看戲」有趣 | 兵種「嘰咕語」語音、陣亡與勝利的短叫聲 |
| Slay the Spire／Cult of the Lamb | 選單轉場、卡片懸停放大、手繪介面框 | 九宮格手繪框、轉場動畫 |

## 2. 方案（依類別）

### A. 聲音（最高優先：花費最低、效果最明顯）
- A1 音樂：換成**真人作曲**或**授權曲**（標題、擺陣、戰鬥、狂熱、勝利、失敗 6～8 首），44.1kHz 立體聲 OGG，每首 1.5～3 分鐘可循環。現有分軌設計（戰鬥鼓、貝斯、旋律依戰況加入）保留，請作曲者照分軌交件。
- A2 戰鬥音效：換成錄音或高品質素材庫（Freesound CC0、Sonniss GDC 免版稅包等），**分層**做打擊：錄音的撞擊＋合成的呼嘯＋低頻重量；每種音效 3～5 個變體隨機挑＋音高微調，避免重複感。授權逐條記在 `licenses/`。
- A3 角色聲音：每種兵一組 2～3 個短「嘰咕語」（出擊、受擊、倒下、勝利），可愛不說人話（參考 TABS、Animal Crossing）。
- A4 混音：分匯流排（音樂、音效、介面、語音）、戰鬥激烈時音樂自動壓低（ducking）、限制同時發聲數（已有）、整體響度統一。
- A5 介面音：同一套材質（木頭、紙、金屬）的點擊、懸停、翻頁，和美術風格一致。

### B. 角色（兩條路並行）
- B1 程式繪製升級（自製、零授權風險）：
  - 外輪廓粗、內線細（現在一樣粗）；外框顏色用角色主色加深，不用同一個深紫。
  - 一層明暗：身體下半部陰影、頭頂高光、臉頰腮紅已有，補金屬反光（盾、刀）。
  - 紙張顆粒材質疊在角色上（低透明度），打破「完美向量」。
  - 可選「線條微抖」（每 2～3 幀換一次位移，手繪動畫的 boil）：設定可關。
  - 腳底影子改成柔邊橢圓；受擊白閃改成角色剪影閃白（不是一顆圓）。
- B2 外包手繪（建議做在「最常被看到的地方」）：
  - 兵種圖鑑立繪 22 張（大圖，圖鑑與簡介卡用）。
  - 標題主視覺插畫 1 張、Steam 膠囊圖組。
  - 戰場上的小兵可以維持程式繪製（B1），讓手繪立繪「帶」整體質感，成本可控。
  - 若預算夠，再談戰場角色換成逐格手繪精靈圖（22 種 × 動作 8～12 格，工時最大，先做 3 兵試點）。

### C. 場地
- C1 其他 5 張地圖照平原做法換成手繪或素材包地塊與物件（樹、石、冰、熔岩、峽谷），每張一組色票。
- C2 每張地圖一個調色（LUT 或簡單色彩矩陣）＋暈影；黃昏、夜晚（已有外觀欄位）真正換光。
- C3 環境動態：飄葉、落雪、熔岩火星、河面反光、雲影掠過地面（低透明度大片陰影慢慢移動）。

### D. 介面
- D1 九宮格貼圖框：木框、紙卷、金邊三種材質，取代程式方框；按鈕有正常、懸停、按下、停用四態貼圖。
- D2 圖示換成一致風格的手繪或授權圖示集（目前程式畫的 40 個）。
- D3 字體：標題字已有（ThenKhung）；內文選一套更有個性但好讀的字（需支援繁中、授權可商用、可子集化）。
- D4 轉場：開關覆蓋層淡入＋輕微放大（約 0.2～0.3 秒、進場減速、離場加速）；換畫面用一張紙捲或布幕擦過；設定可關（減少動態）。
- D5 微互動：按鈕懸停微抬、按下壓扁回彈；卡片懸停放大傾斜（Balatro）；數字變化用「數上去」；星星一顆一顆落下有音效。
- D6 結果頁演出：勝負橫幅落下 → 戰力走勢畫出 → MVP 卡翻面 → 星數逐顆亮，每段 0.2～0.4 秒，可點一下跳過。
- D7 游標：自訂小手套／劍形游標，懸停按鈕時變化。

### E. 特效與鏡頭
- E1 改用粒子節點做打擊火花、塵土、碎片、魔法光點（目前是程式畫的幾何）。
- E2 技能與大招加泛光（只在發光物件上）。
- E3 鏡頭：開戰時從敵陣平移到中線、關鍵時刻已有慢動作與推近，補輕微的鏡頭晃動衰減曲線。
- E4 角色描邊與受擊閃白改用著色器（社群有 Godot 4 免費包：外框、受擊閃白、溶解、閃光），省掉現在的程式疊圓。

### F. 包裝與第一印象
- F1 標誌（Logo）設計：中英文字標＋小圖形，用在標題、膠囊、啟動畫面。
- F2 開場：工作室或作者名片 1 秒 → 標題主視覺淡入，背景模擬戰保留但加一層暈影。
- F3 讀取畫面、成就跳出通知、製作名單捲動。
- F4 Steam 頁面：先做小膠囊（最小尺寸也要讀得到標題）、5 張以上真實遊玩截圖、預告片開頭就是實際遊玩（Valve 建議）。

### G. 手感與細節
- G1 手把震動：命中、斬首、勝利（設定可關）。
- G2 文案潤飾：全遊戲語氣一致（可愛但不幼稚）、英文請母語者校稿。
- G3 數字與單位的排版一致（全形／半形、空格）。

## 3. 技術配套
- 新美術全部走現有圖集（`sprite_cache.gd`）與版面檢查；新增「材質層」不影響模擬，FINGERPRINT 不變。
- 著色器先做「可關」開關與效能預算（繪圖 p95 不超過現在 +10%）。
- 素材授權逐條登記在 `licenses/` 與 `docs/release/`；外包合約要寫清楚商用與修改權。
- 音樂分軌照現有 `music_battle_*` 架構交件，程式只換檔案。
- 截圖測試要加「轉場中」與「演出中」的固定時間點。

## 4. 優先序與 CP 值

| 優先 | 項目 | 為什麼 | 做法 |
|---|---|---|---|
| P0 | A1 音樂、A2 音效、A4 混音 | 電腦感最大來源；換檔案即可，程式改動小 | 外包作曲或授權曲；音效素材庫＋分層 |
| P0 | D4 轉場、D5 微互動、D6 結果頁演出 | 自製、零授權成本，立刻「有彈性」 | 程式 |
| P0 | B1 角色程式升級（外框粗細、明暗、紙紋） | 自製、所有畫面都受益 | 程式＋截圖比對 |
| P1 | D1 九宮格框、D2 圖示 | 介面從「工具」變「遊戲」 | 素材包或外包 |
| P1 | B2 圖鑑立繪、F1 標誌、主視覺 | 第一印象與商店頁 | 外包 |
| P1 | C1～C3 地圖材質、調色、環境動態 | 地圖之間質感一致 | 素材包＋程式 |
| P2 | E1～E4 粒子、泛光、著色器 | 加分 | 程式 |
| P2 | A3 角色聲音、G1 震動、D7 游標 | 加分 | 外包配音或自製 |
| P3 | B2 戰場逐格手繪精靈圖 | 最貴、風險最高 | 先 3 兵試點再決定 |

## 5. 里程碑
- M1 聲音與動態（P0）：音樂與音效到位、轉場、微互動、結果頁演出、角色程式升級。驗收：試聽表重做、版面全量、繪圖預算、真人 3 人試玩回饋「不像電腦」。
- M2 介面材質與包裝（P1）：九宮格框、圖示、標誌、主視覺、圖鑑立繪、Steam 頁。
- M3 場地與特效（P1～P2）：5 張地圖材質與調色、環境動態、粒子與著色器。
- M4 選做：角色聲音、震動、戰場手繪精靈圖試點。

## 6. 需要使用者決定的事
1. **預算**：音樂外包或授權曲、美術外包（立繪 22 張、主視覺、標誌、介面框）要不要花錢、上限多少。沒有預算的話，P0 全部可以自製或用免費素材完成，P1 改用素材包。
2. **美術方向**：維持現在的 Q 版向量風格做「質感升級」（B1），還是往「手繪繪本風」走（B2 擴大）。
3. **角色聲音**：要不要嘰咕語配音（有些玩家覺得吵，會做開關）。

## 7. 不做
- 不改模擬與數值、不改玩法（這一版只做質感）。
- 不用 AI 生成美術當正式素材（授權與風格一致性風險，也容易被玩家批評）。
- 不換引擎、不換成 3D。
